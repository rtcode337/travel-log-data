# tourist(観光地)

- 日本全国の観光地 **10,712件**。travel-log側の唯一の既定スポット種別
- 出典: Wikipedia(ja)の「○○の観光地」47都道府県ページ。座標はWikipedia記事座標・Wikidata `P625`
- ライセンス: **CC BY-SA 4.0**(説明文・座標)+ **CC0**(Wikidata由来の座標)。
  再配布時は出典表示が必要(→[ライセンス](#ライセンス))

| ファイル | 内容 |
|---|---|
| `spots.csv` | スポットデータ(10,712件) |
| `settings.json` | スポット種別の設定(ランクの有効化・シリーズ11種とアイコン・カテゴリ) |
| `effort_basis.csv` | `categories`の`じっくり`をどう判定したかの根拠(`key,effort,rule,evidence`) |
| `excluded_candidates/01_hokkaido.md` 〜 `47_okinawa.md` | 除外した候補と理由(都道府県別、参考資料) |
| `excluded_candidates/series_demotions.md` | ランクを目視で格下げしたスポットの記録(当時の呼称はシリーズ) |
| `excluded_candidates/exclude.txt` | travel-log側から削除するスポットの`key`一覧(追記式) |
| `excluded_candidates/events.csv` | 行事の記事として外した32件をそのまま残したもの(祭りのスポット種別を作るときの種。列は`spots.csv`と同じ) |

`tourist`はtravel-log側の既定スポット種別で、`spot_types`の行はアプリ初期化時に自動で作られる。
ただしスポットデータ自体は他の種別と同じで、ここに置くCSVがそのまま取り込み用の参照データ
(travel-log本体側に複製は持たない)。`settings.json`もtravel-log側では`db/init/01_schema.sql`が
直接種別を作成するため実際には使われず、現状の設定を文書化するためだけに置いてある
(かつては`db/init/tourist_spots.csv`として本体にも複製し自動投入していたが、
下記ライセンスの理由により廃止した)。

## 出典と生成

Wikipedia(ja)の**「○○の観光地」47都道府県ページ**を唯一のスポット候補ソースとして機械生成した。
かつてOverpass API(OSM)から一括取得していた版は、観光地ページに載っていないスポットを大量に
含む一方で重要スポットの取りこぼしもあったため、全件を作り直した。

ランク(A〜E。CSVの`rank`列。**かつては`series`列だった**)は主観ではなく、
**Wikipedia(ja)の月次ページビュー数**(bot除外)を知名度の
客観指標としてパーセンタイル区分している(生成当時の観光地11,628件中の相対順位)。最上位をSにすると
運用上何かと面倒なため、A〜Eの5段階にしている。

| ランク | 相対順位 | 目安 |
|---|---|---|
| A | 上位5% | 全国的に絶対外せない |
| B | 次15% | 全国区で有名 |
| C | 次30% | 地方の定番 |
| D | 次30% | 地元で知られている |
| E | 残り20% | 穴場・マニアック向け |

生成手順(スクリプトはリポジトリに含めていない一時作業):

1. 「○○の観光地」47ページのwikitextから記事内リンク20,347件を抽出(テンプレート由来の
   ナビゲーションリンクを拾わないよう、レンダリング後のリンク一覧ではなくwikitextを使う)
2. リダイレクトを解決して同一記事を1件に統合し、赤リンク・曖昧さ回避・一覧ページ・
   祭事/イベント・作品(ドラマ等)・市区町村そのものの記事・都道府県そのものの記事、
   および**代表点1つでは表現できない広域地物**の記事を除外(次項「収録する場所の単位」)
3. 座標はWikipedia記事の位置情報→Wikidata `P625`の順に採用し、どちらにも無いものは除外。
   当初はさらにOSM(同名地物の完全一致のみ)で座標を補完していたが、touristから
   ODbL(OpenStreetMap)の表示義務を外すため、2026-07-23に全件をMediaWiki Action API・
   Wikidata APIと突き合わせ直し、座標がWikipedia記事座標・Wikidata `P625`のいずれとも
   一致しない行(OSM由来の補完分など)を除外した。現在の座標の内訳は**Wikipedia記事座標
   9,282件・Wikidata `P625` 1,501件(計10,783件)**で、全件がWikipedia記事座標または
   Wikidata `P625`(±0.001度以内)と一致する(この2026-07-23再生成時点の件数。以降、
   令制国6件・路線そのもの2件(東名高速道路・箱根ターンパイク)を2026-07-26に除外、さらに
   同一座標で重なるスポット37件(横浜みなと博物館ほか。妙高戸隠連山国立公園は分離元の上信越
   高原国立公園へ)を同一地点の主要スポットへ統合、線状の別子ライン1件と、出典の座標自体が
   誤っていたアトア1件を除外し10,736件。一部の同一座標(横浜開港資料館と神奈川県立歴史
   博物館など)は座標を精緻化して分離した。さらに2026-07-26のシリーズ点検の際に、既存基準の
   除外漏れだった全国チェーン企業・訪問先の無い企業そのもの・閉業済み施設の12件
   (ビックカメラ・味の素・三井アウトレットパーク 大阪鶴見ほか)を除外し10,724件、
   同日の再点検で閉業・解体済みで現存しない施設12件(ノースサファリサッポロ・
   広島市民球場(初代)ほか)と観光道路の路線そのもの1件(磐梯吾妻道路)をさらに除外し10,711件。
   2026-07-30に、記事から訪問先性を確認できない町丁そのものの記事3件(佃 (東京都中央区)・
   八木が谷・須崎 (下田市))を除外し10,708件。2026-08-01に、同一座標で重なるために
   統合していた37件のうち36件を復元して10,744件 — travel-log側が重なったピンに
   「+N」バッジを出して選べるようにしたため、重なりを理由に統合する必要が無くなった。
   復元しなかった1件は谷津遊園で、かつて存在した遊園地(1982年閉園)のため
   「閉業済み施設を収録しない」という別の基準に当たる。**2026-08-09に、地域区分
   そのものの記事1件(東京都区部。単一の市区町村名ではない総称記事のため除外フィルタを
   すり抜けていた)を除外し10,743件。**2026-08-10に、記事から訪問先性を確認できない
   町丁そのものの記事1件(中野木)を八木が谷と同じ理由で除外し10,742件。
   **2026-08-11に、閉業済みで現存しない遊園地3件(ひめじ手柄山遊園・西鉄香椎花園・
   比叡山頂遊園地)を除外し10,739件** —— 下記「シリーズの拾い直し」で遊園地を
   新設した際に、冒頭文が過去形の行として見つかったもの。**同じ日に、事件・戦いの記事の
   うち跡地に碑・史跡が現存する2件(生麦事件・嘉数の戦い)を収録して10,741件**
   —— 下記「収録する場所の単位」の例外。**同じ日に、2023年に解体され現存しない
   北海道百年記念塔1件を除外して10,740件。**同じ日に、イベントの記事1件
   (鹿島ガタリンピック)を除外して10,739件** —— 座標が佐賀県ではなく黄海上・
   region も長崎県で、どちらも誤っていた。**同じ日に、民俗芸能・祭りの記事32件を除外し、
   開催地5件を追加して現在10,712件** —— 下記「行事の記事を外して開催地を足す」)
4. `description`はWikipedia記事の冒頭1文、`name_kana`は冒頭文の読み仮名から機械抽出。
   ただし**町名・地区名・通称の記事は冒頭1文が地域区分の定義で終わってしまい、
   なぜ訪問先なのかが伝わらない**ため、2026-07-30に該当48件を記事の2文目以降から書き直した
   (例: 汐留は「東京都港区の地区名・旧町名。」→ 再開発地区「汐留シオサイト」であることを追記)。
   **2026-08-10に、この書き直しが効いていなかった13件を同じ方針で直した**
   (汐留・歌舞伎町・秋葉原・道玄坂・一番町 (仙台市)・元町 (神戸市)・日本橋 (大阪市)・
   堀江 (大阪市)・国友・園原・油壺・中洲・六角橋)。
   **同じ日に、`description`へ紛れ込んでいた出典脚注を全件除去した**(353件)。
   冒頭文の機械抽出がWikipedia記事中の参考文献・注釈をそのまま取り込んでいたもので
   (`…にある神社角川日本地名大辞典編纂委員会編『角川日本地名大辞典13 東京都』…1004頁。`)、
   MediaWiki Action APIの`prop=extracts&exintro&explaintext`が返す**脚注を含まない本文**から
   冒頭1文を取り直して差し替えた。末尾の肩書きは元の値を保ち、
   同じ原因で壊れていた肩書き(`日本三名瀑・日本三名瀑の一つ。`など)も付け方の規則に沿って整えた。
   さらに`description`の末尾に、その場所の**肩書き(国の指定・登録・選定)**を
   `世界遺産・国宝・特別史跡・日本100名城・日本さくら名所100選。`のように追記している
   (3,180件=全体の29%に付与。下記「肩書きの付け方」参照)
5. `region`は冒頭文中の都道府県名(無ければ掲載元ページの都道府県)。座標が
   その都道府県の範囲から外れるものは、県内の同名OSM地物で座標を取り直すか、
   座標側に合わせて`region`を付け替える
6. `rank`は月次ページビューの全国パーセンタイル、`series`・`categories`は記事名・冒頭文の
   キーワードによる機械分類のため、いずれも精度にはばらつきがある
7. `series`は **自然2,040 / 博物館他1,355 / 公園1,100 / 寺院1,012 / 商業施設998 /
   神社900 / 温泉551 / 城跡・史跡422 / 建造物410 / レジャー施設348 / 街並み120**
   (計9,256。残り1,456件はシリーズ無し)。
   **2026-08-11に、それまでカテゴリだったものをシリーズへ移した** —— 地図ピンの
   中身(アイコン)はシリーズが決めるようになり、カテゴリは絞り込み専用になったため。
   移したカテゴリは`categories`から外してある(同じ意味の値が2か所に残らないように)。
   - **`神社仏閣`は`神社`と`寺院`に分けた**。判定は記事の冒頭文と名前のキーワード
     (祭神・鳥居・式内社 / 本尊・山号・宗派・札所など)で、どちらとも決まらなかった
     **8件はシリーズ無し**にしている(川原毛地獄・湯島聖堂・室堂・穴の谷の霊水・
     将軍塚・大峯奥駈道・紀伊山地の霊場と参詣道・多久聖廟 —— 儒教の廟・修験の道・
     霊場など、神社でも寺院でもないもの)
   - **`美術館博物館`と`動物園・水族館`は`博物館他`にまとめた**。地図記号が
     この5種(博物館・美術館・動物園・水族館・植物園)で1つだから
     ——ただし国土地理院の定義では動物園・水族館・植物園は記号ではなく注記で
     表示するもので、記号の対象外。ここでは同じ「入って中を見る施設」として
     1つのシリーズにしている。**`博物館`ではなく`博物館他`という名前**なのは、
     動物園や水族館がなぜここに入るのか、名前だけでは読めないため。
     **名前に`植物園`を含む39件**は`自然`からこちらへ移した(34件が`自然`だった)
   - **`商業施設`もシリーズへ移した**。地図記号が無いので買い物袋を自前で描いたが、
     **他の記号と同じ線画にしてある** —— 塗り潰した袋は小さいピンでは輪郭の分からない
     塊になり、何の絵か読めないため。**袋は下すぼまりにしない**(すぼめるとゴミ箱に見える)
   - **`街並み`もシリーズへ移した**(119件)。アイコンは高さの違う切妻屋根を2軒
     —— 屋根を3つ並べると小さいピンで山が潰れ、1軒だと`博物館他`と紛らわしい
   - **`公園`は新設**(907件)。カテゴリには無かったので、**名前に
     `公園`・`緑地`・`庭園`・`園地`を含み、まだシリーズが無いもの**を拾った
     (該当は1,231件あるが、`自然`273・`博物館他`24・`城`22などが既に付いている
     行は動かしていない)。アイコンは噴水 —— 木は`自然`の針葉樹と被り、
     ベンチは「横棒2本+縦棒2本」で`神社`の鳥居と骨格が同じになってしまうため避けた。
     `温泉`(湯壺と湯煙)とは、外へ広がる水の弧・台座・基壇で見分ける。
     **同じ日の見直しで198件を追加し1,099件になった**(下記「公園の拾い直し」)
   - **`遊園地`を新設した**(88件。下記「遊園地の新設」)。**同じ日に`レジャー施設`へ
     改名してスキー場・スポーツ施設を含め、`建造物`も新設した**(下記「シリーズの広げ方」)
   - 既にシリーズが付いていた行は動かしていない(植物園だけ例外)。
     `自然`+`商業施設`のように両方に当たる行が7件あるが、先に付いたほうを残した
   - アイコンは**地図記号を実際の座標から自前で描き起こした**
     (神社=鳥居 / 寺院=卍 / 城跡・史跡=縄張 / 温泉=湯壺と湯煙 / 博物館他=建物 /
     自然=針葉樹)。**線で定義された記号を、塗りで描く輪郭に変換してある**
     ——travel-log のピンはパスを塗って描くため。地図記号が無い
     `商業施設`(買い物袋)・`公園`(噴水)・`レジャー施設`(観覧車)・`建造物`(塔)は
     自前の意匠だが、同じ線画にそろえてある。
     `街並み`(高さの違う2軒)だけは**塗りのシルエット** —— 線画で2軒描くと
     壁どうしが線の太さでくっつき、ピンの大きさでは1軒の塊に潰れるため
8. `categories`は **全件空**になった。分類の軸がシリーズへ移り、最後に残っていた
   「どのシリーズにも当てはまらない」印の`その他`も外したため、いまカテゴリを使う
   スポットは無い(絞り込みの選択肢も出ない)。
   - **`じっくり`(769件)は2026-08-11に外した**。判定の根拠は`effort_basis.csv`に
     全件ぶん残っているので、付け直せる
   - `動物園・水族館`(2026-08-11新設。それまで「入って中を見る施設」として
     `美術館博物館`に入っていた)は、同じ日に`博物館他`シリーズへ吸収された
   判定そのものは`effort_basis.csv`に全件ぶん残っているので必要なら戻せる。
   **商業施設は2026-08-10に新設**した —— それまでモール・百貨店・アウトレット・
   駅ビルの類は`その他`に埋もれていて、地図でも一覧でも他と見分けられなかった。
   付与は冒頭文の施設種別の語(ショッピングセンター・複合商業施設・アウトレット・
   百貨店・駅ビル・地下街など)で抽出した238件から、**商業施設が構成要素・入居先に
   すぎず主目的が別の施設のもの4件**(北九州市漫画ミュージアム・横浜アンパンマン
   こどもミュージアム・横浜・八景島シーパラダイス・箱根園)を除いた234件。
   付けた行からは`その他`を外している(「どれにも当てはまらない」の意味のため)。
   **ランクは動かしていない** —— 商業施設の格下げは2026-07-26に
   `excluded_candidates/series_demotions.md`の基準で実施済みで、
   「観光文脈が明確なものは据え置き」の判断もそのまま保っている

## シリーズの拾い直し(2026-08-11)

シリーズを付けた当日の見直しで、**判定を「名前」から「冒頭文の述語」へ変えた**。
述語とは「◯◯は、…にある□□である」の□□で、記事がその場所を何と定義しているか。
名前で見ると池上梅園(区立公園)・偕楽園(日本庭園)・兼六園・後楽園・新宿御苑のように
**公園なのに名前に「公園」が入らない**ものを全部落とす。かわりに冒頭文のどこかに
「公園」があれば拾う方式にすると、こんどは「大通公園内にある展望塔」のような
**所在地としての言及**まで公園になる。述語だけを見れば、どちらも正しく扱える。

### 公園の拾い直し(907→1,099件。198件追加・6件を`遊園地`へ移動)

**述語が公園・庭園・緑地・園地・公苑・御苑、または花木の園**(梅園・バラ園・藤園・
コスモス園・ラベンダー園など)**で終わり、まだシリーズが無い行**が164件。これに、
述語の後ろに説明が続いて末尾一致しない27件を名指しで足した(後楽園「日本庭園で、
日本三名園のひとつ」・識名園「琉球庭園の一つ」・くりはま花の国・横須賀しょうぶ園・
太閤山ランド・皇居外苑・どんどんどんの森など)。残る7件は下記のテーマパークからの移動分。

外したものと理由:

- **霊園・墓地**(6件。多磨霊園・青山霊園・谷中霊園・雑司ヶ谷霊園・小平霊園・
  東京都立八柱霊園)—— 公園ではない
- **動物・鳥・魚・昆虫の展示施設**(ネオパークオキナワ・たびら昆虫自然園)
  —— 名前と述語は公園・園だが中身は展示施設なので`博物館他`へ回した(下記)
- **原生花園**(ワッカ原生花園)—— 人の造った園ではないので`自然`へ回した(下記)
- 述語が別の施設で、所在地として公園に触れているだけの行(野球場・展望塔・西洋館など)

**運動公園・総合公園は述語どおり`公園`に入れた**(岡山県総合グラウンド・
奈良県立橿原公苑・千葉県総合スポーツセンターなど)。同じ敷地でも、スタジアム単体の
記事は述語が「野球場」「陸上競技場」になるので入らない。

### 遊園地の新設(88件)

述語が**遊園地・テーマパーク・アミューズメントパーク・ディズニーパーク・
ミニチュアパーク・ウォーターパーク**の行。**名前は`遊園地`だがテーマパークも含む**
—— 地図記号が無いので括り方は自前で決めることになり、「乗り物・アトラクションで遊ぶ
施設」を1つにした(`博物館他`と同じで、名前だけでは範囲が読めないぶんここに書く)。
アイコンは**観覧車**(輪+6本のスポーク+A字の脚)—— コースターは線が絡まって
小さいピンで潰れる。`公園`(噴水)とは輪の抜けで見分ける。

- **既にシリーズが付いていた7件も移した**。伊豆ぐらんぱる公園・生駒山上遊園地・

## 説明文の修復(2026-08-11)

`description`は「Wikipedia記事の冒頭1文＋肩書き」で機械生成しているが、抽出が記事の
**脚注・出典・画像の説明・展開されなかったテンプレート**を巻き込んでいた行が残っていた。
**1,067件**を直した(内訳: 本文の取り直し469件 / 表記の掃除380件 / 肩書きの掃除195件 /
本文と肩書きの両方23件)。2026-08-10に脚注の除去を353件行っているが、そのとき拾えなかった
種類が残っていた。

### 直し方

本文は**MediaWiki Action APIの`prop=extracts&exintro&explaintext`**(脚注を含まない本文)から
冒頭1文を取り直した。chiezoのjawikiにも冒頭文はあるが、**注釈テンプレートが本文に
展開されて混ざっている**ため(NIFRELの「所在地の実際は、…」がまさにそれ)このズレを
見るには使えない。全10,739件を1リクエスト20件・1.2秒間隔で取得して突き合わせている。

**取り直す条件**(全件を上書きするのではない):

- 括弧の外の文が今の記事の冒頭1文と違う。**括弧の中だけの違い(読み・英語表記の有無)では
  入れ替えない** —— 全件に英語表記が入って別の作業になる
- ただし次は触らない —— **CSV側が2文以上ある行**(2026-07-30・08-10に町名・地区名の記事を
  2文目以降から書き直した分。上書きすると書き直しが消える)、CSV側が記事の冒頭文を
  途中で切ってあるだけの行、余計な部分が「である」だけの行
- 逆に、**展開されなかったテンプレート・画像の説明が付いている行は必ず取り直す**
  (`__NOTOC__`・`|300px|thumb`・`代替文=…|サムネイル|…`・`{{旧字体|…}}`)。
  これらは**本文の頭に付く**ので「冒頭がスポット名で始まる」の判定が使えない
- 記事側の冒頭文のほうが壊れている5件(常陸國總社宮・雲巌寺・駒沢オリンピック公園・
  豊田市小原和紙のふるさと・有楽町センタービル)は目視で除外した

直した中身の例:

| 直したもの | 例 |
|---|---|
| 注釈が本文に流れ込む | NIFREL「…千里万博公園内**所在地の実際は、吹田市の千里丘陵にある万博記念公園の中**。」 |
| 出典の題名が末尾に付く | 胆沢ダム「…特定多目的ダムである**胆沢ダム 国土交通省　北上川ダム統合管理事務所**。」 |
| 画像の説明が頭に付く | 北海道博物館「**内部に復元されたアイヌ民族の伝統住居「チセ」\|300px\|thumb** 北海道博物館…」 |
| 誤字 | 司馬**遼**太郎記念館(「遼」が落ちていた) |

### 表記の掃除(380件)

読み・外国語表記を落とした跡の**空括弧**「（）」「（ススキノ、薄野、）」「（、、）」、
句読点の前の空白、**括弧の対応ずれ**(（で開いて`)`で閉じている・「））」と重なっている)を
直した。半角括弧を全角に寄せるのは**対応が取れていない行だけ**で、英語表記の中の
ASCII括弧には触らない。記事側の括弧が閉じていない1件(国立オリンピック記念青少年総合センター)は
手で閉じ括弧を補った。

### 肩書きの掃除(195件)

肩書き(`世界遺産・国宝・…100選。`)は記事の文中から拾ったため、次の3つが混ざっていた。
**正しい選定名の語彙を実データから作り、トークンの前後に付いた余計な部分を削る**方式で直した。

- **前置きの断片**: 「日本の滝百選・**90年（平成2年）に**日本の滝百選」→「日本の滝百選」
- **途中で切れた語**: 「日本三百名山**のひ**」「日本三名橋のひと・日本三名橋**とは!**」→「日本三百名山」「日本三名橋」
- **役所名だけが違う重複**: 「ため池百選・**農林水産省**ため池百選」→「ため池百選」

語彙は頻度だけでは作れない(**同じ断片が何行にも現れる** ——「月25日に農林水産省のため池百選」は
10行、「日本三文殊のひと」は2行あった)ため、数字・「選定」「として」などを含む形や
途中で切れた形を語彙から外している。機械では決まらない7件(「っぽんの温泉100選」→
「にっぽんの温泉100選」、「し阿波お勧めビューポイント100選」→「にし阿波お勧めビューポイント100選」など)は
記事本文で確かめて表にした(残った「日本三大胃腸病の名」→「…の名湯」など2件は手で直した)。

あわせて、**読む人には関係のない内部メモ**「（同一座標のため統合）」を4件から落とした
(同一座標のスポットを統合した記録。経緯は上記「出典と生成」に書いてある)。

### 直していないもの

- **弘前城**「陸奥国鼻和郡（のち統合と外浜（青森）、西浜（十三湊）を編入で津軽郡）弘前…」——
  記事側の冒頭文が同じ形なので、この経路では直せない
- 記事の冒頭が変わっただけの行は取り直しの対象になる(壊れていたかどうかで分けていない)。
  出典が今の記事に揃うため、これは意図した挙動

初回生成では市区町村・祭事の除外に取りこぼしがあり(神奈川区・新宿区・唐津くんちなど)、
広域地物にはそもそも基準が無かったため、後から上表の基準で538件を除外した
(11,628→11,090件)。**大学・ゴルフ場は「訪問先か」の判断がスポットごとに割れるため、
今回は一律に残してある**(北海道大学のように観光地として定着している例があるため)。

CSVから外したスポットの`key`は`excluded_candidates/exclude.txt`に追記してあり、
travel-log側の`/[type]/admin`「キー一覧を指定して削除」に貼り付けるとDBからも消せる
(CSVの再取り込みは差分更新のため、行を消しただけではDBには反映されない)。
除外した候補とその理由は`excluded_candidates/`に都道府県別に残してある
(取りこぼしを後から検証・救済できるようにするため)。

世界遺産・国宝等の指定があるがページビューが伸びにくい場所は、目視で格上げする例外を許容する
ハイブリッド方式(完全自動ではない)。逆に、**受験・就活・企業情報・日常の買い物など、
ページビューの由来が観光でないスポット(大学・企業・商業施設)は目視で格下げする**
(2026-07-26にA・Bの該当133件を全件点検し64件を格下げした。個々の変更と理由・据え置きの
一覧は`excluded_candidates/series_demotions.md`参照)。travel-log側で手動でスポットを
追加する場合も、この基準を参考にランクを付けるとブレにくい。

## 肩書きの付け方(`description`末尾の「なぜ観光地なのか」)

- 出典はWikipedia記事の**カテゴリと冒頭文**で、LLMによる生成文は使っていない
  (検証できない文をデータに混ぜないため)。強い順に最大5個まで`・`で連結する
- 対象は制度に基づく指定・登録・選定のみ: 世界遺産/国宝/特別史跡・特別名勝・特別天然記念物/
  重要文化財/重要伝統的建造物群保存地区/重要文化的景観/国の史跡・名勝・天然記念物/
  登録有形文化財/日本遺産/近代化産業遺産/ラムサール条約登録湿地/ジオパーク/国立・国定公園/
  日本100名城/日本百名山・日本百景・○○100選(百選)の各種選定
- 上位互換がある場合は下位を落とす(特別史跡があれば国の史跡は書かない、国宝があれば
  重要文化財・登録有形文化財は書かない)
- **博物館・美術館・資料館・記念館は、カテゴリだけを根拠に国宝・重要文化財を付けない**
  (収蔵品の指定を自館の肩書きとして拾ってしまうため。冒頭文に建物自体の指定が
  書かれている場合のみ付ける)
- 付与率は29%。動物園・水族館・展望台・スキー場・テーマパーク・道の駅・繁華街は
  そもそも指定制度の対象外なので肩書きが付かない。**肩書きの有無は観光地としての
  価値とは別の軸なので、収録可否の基準には使わない**(知名度の軸はページビューのA〜Eが担っている)

## `じっくり`(お金と時間がかかるスポット)

`categories`の2値目として付けている旅程用のラベル(例: `美術館博物館|じっくり`)。
判定の基準・根拠ファイル`effort_basis.csv`の使い方は
[../CLAUDE.md](../CLAUDE.md)の「観光地の`じっくり`」節が正。

## ライセンス

- **説明文**(`description`列): Wikipedia記事の冒頭文を引用または要約したもので
  [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.ja)
  (一部旧記事はGFDLとのデュアルライセンス)。利用時は出典(「出典: フリー百科事典
  『ウィキペディア(Wikipedia)』」+該当記事名・URL)の表示と、改変物を同一(または互換)
  ライセンスで提供することが求められる
- **座標**(`lat`/`lng`列): Wikipedia記事の位置情報(9,282件、CC BY-SA 4.0)または
  Wikidata `P625`(1,501件、[CC0](https://creativecommons.org/publicdomain/zero/1.0/))由来
- **ODbL(OpenStreetMap)由来のデータは含まない**。2026-07-23の見直しでOSM補完分の座標を
  全件排除し、Wikipedia + Wikidata由来に統一した。**この状態を崩さないこと** —
  例えば飲食店をここへ混ぜるとODbLの表示義務が復活する
  (飲食店は座標が全件OSM由来のため[restaurant](../restaurant/README.md)に分けてある)
