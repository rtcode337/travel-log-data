# post_office(郵便局)

- 全国の郵便局 **24,526件**
- 出典: 国土交通省 国土数値情報(郵便局データ P30、平成25年度版)
- ライセンス: **非商用利用限定**。CC BY-SA・ODbLとは別種の制限なので注意(→[ライセンス](#ライセンス))

| ファイル | 内容 |
|---|---|
| `spots.csv` | スポットデータ(24,526件) |
| `settings.json` | スポット種別の設定 |

## 出典と加工

国土交通省 国土数値情報の郵便局データ(P30、平成25年度版)を、travel-logのCSV形式に合わせて
加工したもの。加工の内容は次の2つだけで、名称・座標は元データのまま:

- 行政区域コードを都道府県名・市区町村名に変換(`region`列)
- 郵便局分類コード(普通郵便局・特定郵便局・簡易郵便局など)を`categories`列に変換
