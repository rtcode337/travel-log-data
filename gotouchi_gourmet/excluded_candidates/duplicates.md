# 親記事と二重になっていた行

`節から起こした`行のうち、**親記事と同じ料理を指していて座標も同じ**もの。
地図では1点に完全に重なるので、拡大しても下のピンに気づけない。

「既に独立記事があるものは足さない」(README「独立記事を持たないご当地版」)という
規則は**別の記事と二重になる場合**しか見ておらず、**親記事そのものの言い換え**は
すり抜けていた。親が既にその土地に立っているので、起こした行は同じ場所に増えるだけになる。

## 外したもの(2026-08-17)

| キー | 名前 | 親 | なぜ同じか |
|---|---|---|---|
| `海軍カレー#よこすか海軍カレー` | よこすか海軍カレー | 海軍カレー | 親の座標が横須賀市で、名前は同じ料理の地元表記 |
| `海軍カレー#横須賀海軍カレー` | 横須賀海軍カレー | 海軍カレー | 同上。親の説明文にある鉤括弧から起こしたもの |
| `ヨコスカネイビーバーガー#ネイビーバーガー` | ネイビーバーガー | ヨコスカネイビーバーガー | 親の名前の略称 |

横須賀市の1点に海軍カレーが3件・ネイビーバーガーが2件並んでいた。
`呉海自カレー`(広島県呉市)・`大湊海自カレー`(青森県むつ市)も同じ親から起こしているが、
**別の土地に立つ別のご当地版**なので残してある。

## まだ見ていないもの

同じ形(親と同じ座標に立つ`節から起こした`行)は他に20件ある。
**そのすべてが二重とは限らない** —— 同じ市に別の料理が2つある場合
(`東村山黒焼きそば#東村山ブラックカレー`は焼きそばとカレーで別物)や、
親と作り方の違う派生(`鯛めし#宇和島鯛めし`)が混ざるため、1件ずつ見ないと決められない。
座標が同じというだけで機械的に落とさないこと。

一覧の出し方(`spots.csv`を読み、`#`の前を親のキーとして座標を突き合わせる):

```
python3 - <<'PY'
import csv
rows = list(csv.DictReader(open("gotouchi_gourmet/spots.csv", encoding="utf-8")))
by_key = {r["key"]: r for r in rows}
for r in rows:
    parent = by_key.get(r["key"].split("#", 1)[0]) if "#" in r["key"] else None
    if parent and (r["lat"], r["lng"]) == (parent["lat"], parent["lng"]):
        print(f'{parent["name"]} <- {r["name"]} ({r["key"]})')
PY
```
