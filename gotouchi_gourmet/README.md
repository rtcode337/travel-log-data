# gotouchi_gourmet(ご当地グルメ)

- ご当地グルメ・郷土料理 **553件**。スポットは料理そのものではなく、その料理の**発祥地**
- 出典: Wikipedia(ja)の食のカテゴリの記事。**座標は全件OpenStreetMap**(市区町村の地点)
- ライセンス: **CC BY-SA 4.0**(説明文)+ **ODbL**(座標)。再配布時は出典表示が必要(→[ライセンス](#ライセンス))
- **発祥地の根拠は全行`evidence.csv`に紐づけてある**(どの一文をどう読んで市区町村を決めたか)

| ファイル | 内容 |
|---|---|
| `spots.csv` | スポットデータ(553件) |
| `evidence.csv` | 行の根拠(`key,article,pref,muni,basis,pref_by,sentence,coord,pageviews_month`) |
| `settings.json` | スポット種別の設定(ランクの有効化・シリーズ11種・カテゴリ3種) |
| `excluded_candidates/not_dishes.md` | 収録しなかった候補と理由(33件) |
| `excluded_candidates/exclude.txt` | travel-log側から削除するスポットの`key`一覧(追記式) |

`buratamori`・`suiyou_dodesho_*`が「LLMの記憶」由来で未検証のまま止まっているのに対し、
**この種別はLLMの記憶を一切使っていない**。発祥地はWikipedia(ja)の記事本文から機械的な
規則で取り出しており、根拠の一文を`evidence.csv`に残してあるので突き合わせれば検証できる。

## スポットの単位 —— 「料理」ではなく「発祥地」

1つの料理が1つのスポットになり、置く場所はその料理の**発祥地**。
[restaurant](../restaurant/README.md)が「その店に行く」ための点なのに対し、こちらは
「この料理はここで生まれた」を地図の上に並べるためのもので、**行き先としての実在性は持たない**
(発祥店が現存するとは限らないし、座標は市区町村の地点であって店の場所ではない)。

**発祥地が同じ料理は座標が重なる**(名古屋市にひつまぶし・天むす・鬼まんじゅう・ぴよりんが
集中する等)。ずらしていないのは、ずらすと「発祥地の座標」でなくなるため —— 地図上では
ピンが重なり、拡大するか一覧側で読むことになる。

## 出典と生成

### 母数 —— Wikipedia(ja)の食のカテゴリ

重複を除いた**586件**を調べ、うち553件を収録した。

| カテゴリ | 記事数 |
|---|---|
| 日本の郷土料理 | 364 |
| ご当地グルメ | 150 |
| 農山漁村の郷土料理百選 | 92 |
| ご当地丼 | 45 |

列挙はカテゴリでの絞り込みで行う。**本文の全文検索で`Category:`行を探してはいけない** ——
ソートキー付きの記事(wikitextで`[[Category:日本の郷土料理|きりたんぽ]]`と書かれたもの)は
本文側からカテゴリ名が落ちるため取りこぼす。

### 発祥地の決め方(2段)

**1. 都道府県を決める。** カテゴリ(`○○県の食文化`・`○○県の麺料理`など)を最優先の
手がかりにし、無ければ冒頭文に出てくる都道府県を採る。**本文だけを見てはいけない** ——
「類似の菓子は福岡県にもある」「隣接する徳島県では…」のような文を掴んで、
いきなり団子が福岡県に、鰹のタタキが徳島県になる(実際にそうなった)。

**2. その都道府県の中で市区町村を探す。** 割るのは次のどちらかのときだけ:

| 根拠(`evidence.csv`の`basis`) | 件数 | 何を見ているか |
|---|---|---|
| 冒頭の定義文 | 201 | 記事の書き出しが料理名と市区町村1つだけを結びつけている(「稲庭うどんは、秋田県湯沢市稲庭町が発祥の…」) |
| 発祥を述べる文 | 93 | 発祥・名物・郷土料理を述べる文の中で、市区町村がその語の近く(前後28字)にある |
| 都道府県のみ | 259 | 上のどちらにも当たらなかった。**市区町村までは特定していない** |

**当てずっぽうで市に置くくらいなら都道府県どまりにする**、が方針。ゆるい規則で拾うと
市区町村まで425件まで伸びたが、お好み焼きが神戸市、ほうとうが小鹿野町(埼玉県)になった。
**間違った発祥地は、無いより悪い**(地図の上では正しいものと見分けが付かない)。

### 都道府県どまりの259件をどう置いているか

**県庁所在地の座標**に置き、`categories`を`都道府県まで`にして、`description`の末尾に
「発祥地は○○県内。市区町村までは特定していないため、座標は県庁所在地に置いている」と書く。

- **収録しない選択もあったが、採らなかった** —— 芋煮・きりたんぽ・讃岐うどんのような
  「県全体の郷土料理」がまるごと落ちる。県の代表点であることを明示できるなら、
  出したほうが地図として役に立つ
- **`categories`で絞り込める**ようにしてあるので、発祥地まで割れている294件だけを見ることもできる
- 県庁所在地を代表点にしているのは、県の重心が山中や海上に落ちることがあるため。
  **「県庁所在地が発祥地」という意味ではない**

### 座標

OpenStreetMapの`place=city` / `place=town` / `place=village`のノード(市区町村の地点)。
Wikipedia(ja)の料理の記事は座標を持たないので、記事側からは起こせない
(ライセンス上の帰結は下記参照)。同名の市区町村が複数の都道府県にあるとき
(中央区・府中市など)は、**都道府県が添えられている場合だけ**採る。

### 説明文・読み・ランク・シリーズ

- `description`は記事冒頭の要約(120字程度)に、末尾の丸かっこで発祥地を添えたもの
- `name`は記事名から曖昧さ回避のかっこを外したもの(`ジンギスカン (料理)`→`ジンギスカン`)。
  `key`は記事名のまま
- `name_kana`は冒頭文の読み仮名(304件。持たない記事は空欄)
- `rank`はWikipediaの**月次ページビュー数**(bot除外)。[restaurant](../restaurant/README.md)と
  同じ絶対値のしきい値で区切ってある(母集団が小さくパーセンタイルが安定しないため)

| ランク | 月次ページビュー | 件数 |
|---|---|---|
| A | 10,000以上 | 0 |
| B | 3,000〜9,999 | 21 |
| C | 1,000〜2,999 | 60 |
| D | 300〜999 | 108 |
| E | 300未満 | 364 |

**ランクAが0件なのはしきい値をそろえた結果**(最大はひつまぶしの9,374)。
種別ごとにしきい値を動かすと、ピンの大きさが種別をまたいで別の意味になるため動かしていない。

`series`は料理の種類で、Wikipediaのカテゴリ(`日本の魚介料理`など)から決め、
カテゴリで決まらないものは記事名の語尾で補う(「冷や汁」は`日本の米料理`カテゴリを持つので、
カテゴリだけ見ると丼になる)。

| シリーズ | 件数 | | シリーズ | 件数 |
|---|---|---|---|---|
| 丼・ごはん | 100 | | 菓子・パン | 47 |
| 野菜・漬物 | 65 | | 肉料理 | 39 |
| その他 | 64 | | 寿司 | 36 |
| 麺類 | 64 | | 粉もの | 25 |
| 汁物・鍋 | 59 | | 飲み物 | 4 |
| 魚介料理 | 50 | | | |

**ピンの中身は絵ではなく漢字1字**(麺・丼・鮨・粉・汁・肉・魚・菜・菓・飲・他)にしてある。
料理のアイコンは[restaurant](../restaurant/README.md)が既に持っているので、絵にすると
**同じ地図に両方を出したときに見分けが付かなくなる**(ラーメン店のピンと「麺類」のピンが同じ絵になる)。

### 収録しなかったもの

料理そのものではない記事(一覧・概念・大会・団体・番組・店・企業)と、発祥地を1点に
絞れない記事の**33件**。内訳は`excluded_candidates/not_dishes.md`。

飲食店の記事(`食事処名取屋`)は[restaurant](../restaurant/README.md)の担当なのでここには入れない。

## 既知の限界

- **発祥地は記事の記述に従っている。** 諸説ある料理では記事が採った説がそのまま座標になる
  (ボルガライスは「東京都台東区浅草発祥」と書かれているため台東区に置いてあり、
  ご当地として知られる越前市ではない)。根拠の一文は`evidence.csv`で読める
- **発祥店までは割っていない。** インフォボックスに`発案店`を持つ記事は150件中3件しかなく、
  規則にできなかった。市区町村までが上限
- **料理名に地名を含むものは強い**(富士宮やきそば・佐世保バーガー)一方、
  **全国に広まった料理ほど弱い**(お好み焼き・たこ焼き・ちらし寿司)。後者は
  都道府県どまりになるか、発祥地が書かれておらず収録から落ちている
