# OSM側のwikipediaタグ起点で洗い直した結果(2026-07-30)

これまでの収集は**jawikiの飲食店系タグ → 店名でosm_japanを検索**という一方向で、
「記事名とOSMの店名が一致するもの」しか座標を確定できていなかった。
chiezoのosm_japanが新しいダンプ(20260728)で作り直され、`filter`が大きな`limit`・
深い`offset`でも504にならなくなったため、**逆方向**——OSM側の`wikipedia`/`wikidata`タグから
jawikiの記事を引く——で全件を洗い直した。

## 走査の方法

`filter?feature=` で飲食系の地物を全件ページングし(`limit=500`)、タグに`wikipedia`または
`wikidata`を持つPOIだけを抜き出した。417リクエストで所要1分。

| feature | 総数 | うちwikipedia/wikidataタグあり |
|---|---|---|
| `amenity=restaurant` | 102,990 | 262 |
| `amenity=cafe` | 26,706 | 188 |
| `amenity=fast_food` | 23,672 | 86 |
| `shop=confectionery` | 7,787 | 32 |
| `amenity=pub` | 23,587 | 23 |
| `shop=bakery` | 5,521 | 11 |
| `amenity=bar` / `food_court` / `ice_cream` / `shop=tea` / `pastry` / `coffee` | 15,422 | 11 |
| **合計** | **205,685** | **613** |

613件のうち`wikipedia`タグが`ja:`で始まるもの(379件)はそのまま記事名として使い、
`wikidata`しか無いものは`jawiki/filter?wikidata=Q...`で逆引きした。
結果、**jawikiの記事210件**に解決できた(残り213件は、ミシュラン由来などでWikidata項目は
あるがja記事が無いPOI。jawiki記事の存在を「有名店」のフィルタに使う方針上、対象外)。

**注意**: OSMの`wikipedia`タグは記事の改名に追従していないことがある
(`ja:梅園 (台東区)`→現在は`梅園 (和菓子店)`)。解決できなかったタイトルは
`titles?prefix=`で現行の記事名を探し直すこと。`ja:`の接頭辞が抜けている
(`Ramen_Jiro`)ものもあり、これは言語判定に失敗するので個別に見る。

## 分かったこと

### 1. 既存スポットの座標は正しかった(1件を除く)

210件のうち36件が既存`spots.csv`のスポットに対応し、**35件はOSMが申告する座標と完全一致**した。
残る1件、**首里そば**だけが664mずれていたため、OSM側
(`wikipedia=ja:首里そば`・`addr:neighbourhood=首里赤田町一丁目`)の座標に修正した。

さらに、jawiki記事側が座標を持つ55件と突き合わせたところ**53件が200m以内で一致**した。
不一致の2件はいずれも**Wikipedia記事側の座標が誤っている**もので、CSV(OSM由来)が正しい。

- `茶房長谷路` — 記事の緯度が`35.53`(桜井市は`34.53`)
- `味仙 今池本店` — 記事の座標が今池ではなく名古屋市南部を指している
