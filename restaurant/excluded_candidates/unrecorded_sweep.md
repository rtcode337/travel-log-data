# 母数のうち、名前の記録が残っていなかった候補

[restaurant](../README.md)の候補ソース(飲食店系のタグ)を列挙し直し、**`spots.csv`にも
既存の除外記録にも名前が出てこない記事**を洗い出したもの(2026-08-28)。母数837件のうち
**553件**がこれに当たった。

**きっかけは炭焼きレストランさわやかの取りこぼし。** 初回生成では記事名でOSMを引いており、
OSM側の店名が略称のもの(記事「炭焼きレストランさわやか」/ POI「さわやか菊川本店」)は
1件も当たらず「OSMに該当POIが無い」に落ちていた。そこは**件数しか残していなかった**ため、
何が落ちたのかを後から確かめられなかった。この表はその穴を埋めるためのもの。

## 引き直し方

記事名だけでなく、**記事の中に書かれた別の呼び方**でもOSMを引いた。

- 冒頭の通称(「単に◯◯と呼ばれることが多い」「通称「◯◯」」)
- 本文に出てくる**本店・総本店の名前**(「出店1号店である菊川本店」)
- 引くときは記事の都道府県で絞り(`area=`)、拾えたPOIは飲食系のタグ
  (restaurant / cafe / fast_food / bakery ほか)を持つものだけに限る

| 結果 | 件数 |
|---|---|
| 収録した | 3 |
| 同じ店が別の記事名で既に収録されていた | 1 |
| POIは当たったが記事の店ではなかった | 13 |
| 本店のPOIが見つからない | 536 |

**当たったPOIの多くは「本店」という語が名前に入っているだけの別の店だった。**
「本店」「銀座本店」のような一般的な語で引くと、まったく関係のない店を掴む —— 下表に
1件ずつ理由を書いてある。**引き直しで拾えるのは、店名が記事の中に固有名で書かれているもの**
(ラッキーピエロ ベイエリア本店・彩華ラーメン本店・大砲ラーメン本店)に限られる。

**この表には飲食店以外の記事も混じる。** 母数のタグ(`洋食`・`飲食店`)には
ナポリタン・ハヤシライスのような料理の記事や、飲食店ではない業態の記事も入っているため。
