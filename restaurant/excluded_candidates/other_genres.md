### 誤マッチの引き直し(2026-07-27)

同名の別店を拾っていた8件を、記事に書かれた所在地の範囲でOSMを引き直した。結果、**3件を救済**した。

| 記事 | 結果 |
|---|---|
| 井泉 | **収録**。`井泉 本店`(cuisine=tonkatsu)の`addr`が湯島3-**40-3**と番地まで一致していた。OSM側の`addr:quarter`が「上野」になっているだけで、これが記事の本店だった(誤マッチではなかった) |
| 大黒屋 (桑名市) | **収録**。桑名市多度町の範囲に`鯉料理 大黒屋`があり、記事(鯉料理店)と一致 |
| ぼたん (千代田区) | **収録**。神田須田町の範囲に`cuisine=sukiyaki`のPOIがあり、記事(鳥のすき焼き専門店)と一致 |
| 銀座天一 | 除外のまま。銀座の範囲に該当POIが無い(拾えていたのは上野の店) |
| 中清 (台東区) | 除外のまま。浅草一丁目の範囲に該当POIが無い |
| 天金 (天ぷら) | 除外のまま。1970年閉店で跡地を特定できない |
| スエヒロ | 除外のまま。屋号の解説記事で、そもそも1つの座標で指せない |
| アトム (飲食業) | 除外のまま。持株会社の企業記事 |

引き直しには`search`(店名)+座標での絞り込みを使った。

チェーン企業の記事は、記事側に本店の所在地が書かれるか、OSM側に`branch=本店`が付けば救済できる。
