# restaurant(有名飲食店)

- 有名飲食店 **171件**(飲食店の網羅ではない。**Wikipedia(ja)に記事があること自体を「有名店」の
  フィルタに使っている**)
- 出典: Wikipedia(ja)の飲食店系タグの記事 + OSM側の`wikipedia`/`wikidata`タグ。座標は全件OSM
- ライセンス: **ODbL**(座標)+ **CC BY-SA 4.0**(説明文)。再配布時は出典表示が必要(→[ライセンス](#ライセンス))

| ファイル | 内容 |
|---|---|
| `spots.csv` | スポットデータ(171件) |
| `settings.json` | スポット種別の設定(ランクの有効化・シリーズ12種とアイコン) |
| `excluded_candidates/ramen.md` | 収録しなかった候補と理由(ラーメン83件) |
| `excluded_candidates/other_genres.md` | 収録しなかった候補と理由(ラーメン以外637件) |
| `excluded_candidates/osm_wikipedia_sweep.md` | OSM側の`wikipedia`タグ起点で洗い直した記録(116件) |
| `excluded_candidates/exclude.txt` | travel-log側から削除するスポットの`key`一覧(追記式) |

表示名を「飲食店」ではなく「**有名飲食店**」にしているのは、収録範囲を名前で正しく伝えるため。
[goshuin](../goshuin/README.md)がOSMに名前付きで載っている寺社を無名のものまで全件
(51,950件)収録しているのに対し、こちらは記事のある店だけの171件で、網羅を狙っていない
(飲食系POIはOSMだけで20万件以上ある)。

## 出典と生成

**候補ソースは2系統**あり、Wikipedia(ja)の**飲食店系のタグ(カテゴリ)**に属する記事(113件)と、
OpenStreetMap側の**`wikipedia`/`wikidata`タグが指すWikipedia(ja)の記事**(58件)からなる。
ジャンル別の内訳はラーメン48、日本料理30、喫茶・カフェ25、洋食16、そば・うどん14、
その他13、菓子・パン12、丼もの・定食5、寿司3、中華3、カレー1、焼肉1。

タグ側の候補ソースは、ラーメンが`ラーメン店`(131件)、それ以外が**都道府県別の
`○○の飲食店`39タグ(373件)**と**ジャンル別タグ**(`うどん・蕎麦屋`77・`寿司屋`63・`料亭`49・
`ハンバーガー店`49・`カレー店`26・`焼肉店`23・`ステーキハウス`18・`天ぷら店`11・`とんかつ店`10・
`喫茶店`10・`菓子店`5ほか)。重複を除いて735件を調べた。**「寿司店」「そば店」「中華料理店」
「居酒屋」という名前のタグは存在しない**(寿司は`寿司屋`、そば・うどんは`うどん・蕎麦屋`に
まとまっている)ので、`tags?prefix=`で実在するタグ名を確かめてから列挙すること。

生成手順(スクリプトはリポジトリに含めていない一時作業。すべてWikipedia(ja)と
OpenStreetMapへの問い合わせで完結):

1. **Wikipedia(ja)に記事があること自体を「有名店」のフィルタに使う**(チェーンの一般店舗には記事が無い)。
   列挙は`filter?tag=<タグ名>`。`total`と`offset`でページングする。
   **本文の全文検索(`search?q=Category:ラーメン店`)で列挙してはいけない** — カテゴリに
   ソートキーが付いた記事(wikitextで`[[Category:ラーメン店|らあめんしろう]]`と書かれたもの)は
   本文側からカテゴリ名が落ちるため取りこぼす。初回生成ではこの方法で115件しか拾えておらず、
   **ラーメン二郎**(月17,677PV、ランクA相当)を含む17件が漏れていた
   (2026-07-27にカテゴリでの列挙ができるようになったため列挙し直し済み)
2. **逆方向にOSM側からも引く**(2026-07-30に追加)。`filter?feature=amenity=restaurant`などで
   飲食系のPOIを全件ページングし、`wikipedia`/`wikidata`タグを持つ613件を抜き出して
   Wikipedia(ja)の記事210件に解決した。**タグ列挙だけでは飲食店を網羅できない** —
   名曲喫茶らんぶる・ジャズ喫茶ちぐさのように飲食店系タグに属していない記事や、
   OSMの店名が記事名と違う店(中清→`天麩羅中清`、上野精養軒→`精養軒`、
   並木藪蕎麦→`並木數喬麥`)は1系統では拾えない。詳細と除外理由は
   `excluded_candidates/osm_wikipedia_sweep.md`
3. `description`は記事冒頭の要約(1〜2文)。`name_kana`は冒頭文の読み仮名
4. `rank`(A〜E。**かつては`series`列だった**)は[tourist](../tourist/README.md)・[goshuin](../goshuin/README.md)と同じく
   **月次ページビュー数**(bot除外、2026-06)だが、母集団が小さくパーセンタイルが安定しないため、
   下表の**絶対値のしきい値**で区切っている
5. 座標はOpenStreetMapの店舗POI。Wikipedia(ja)の飲食店記事は座標を持たないことがほとんどで、
   Wikipedia/Wikidata由来の座標ではほぼ収録できないため(ライセンス上の帰結は下記参照)。
   突き合わせは店名+所在地(`area`)での検索と、OSM側の`wikipedia`タグの2通りで、
   **後者は「どのPOIがその記事の店か」をOSMが自己申告している**ぶん確実。本店の判定は
   `branch`タグ(`branch=本店`・`branch=道頓堀本店`)が決め手で、`branch=◯◯店`は支店なので弾く
6. 座標の点検として、Wikipedia(ja)の記事が座標を持つ55件と突き合わせた結果**53件が200m以内で一致**。
   不一致の2件(茶房長谷路・味仙 今池本店)はいずれもWikipedia記事側の座標が誤っており、
   CSV(OSM由来)が正しい

`series`は料理の種類で、**2026-08-11にカテゴリから移した**(地図ピンの中身=アイコンは
シリーズが決めるようになり、カテゴリは絞り込み専用になったため)。全171件がちょうど1つずつ
持っていたのでそのまま移せた。移したあとカテゴリは空。

## 収録の単位

「1つの座標で指せる訪問先か」という[tourist](../tourist/README.md)と同じ基準。

| 種類 | 扱い |
|---|---|
| 単独店(記事の主語が1店舗) | **収録**。座標はその店 |
| チェーンだが本店・創業店を記事から特定できる | **収録**。本店・1号店を代表点にし、`name`を`天下一品 総本店`のように店舗名まで含めて、`description`末尾にどの店の座標かを書く |
| チェーン企業・ブランドそのもの(本店を特定できない) | **除外**(1つの座標で指せない。touristの全国チェーン除外と同じ) |
| 料理・商品・運営会社そのものの記事 | **除外**(場所ではない)。ただし記事の主語が店(「◯◯は…にある和菓子店」)なら製菓・製パンの店も収録する。「◯◯株式会社は…メーカー」と企業を主語にしているものは除外 |
| 飲食店が入っている施設・建築物の記事(道の駅・百貨店・登録有形文化財の邸宅など) | **除外**(記事が飲食店の記事ではない。大半はtourist側の対象) |
| 閉店した店 | **収録可**(跡地・代表点が特定できる場合のみ。今回は該当4件とも座標を決められず未収録) |

本店の特定は、OSMの`branch`タグ(`branch=本店`・`branch=秋葉原本店`など)と店名の`本店`表記を
優先し、記事本文に書かれた本店の所在地(市区町村)と突き合わせて確定した。支店しか
見つからない店は収録していない。収録しなかった候補と理由は`excluded_candidates/`に残してある。

**ジャンルによって当たり方がかなり違う**点に注意。ラーメン店タグは記事の54%がチェーン企業の
記事だったのに対し、都道府県別の`○○の飲食店`タグは12%しかなく、すきやばし次郎・煉瓦亭・
神谷バー・ヨーロッパ軒のような単独の老舗・名店が中心になる。逆に`ハンバーガー店`・`寿司屋`・
`ステーキハウス`はほぼ全国チェーンの企業記事で、`洋食`タグに至っては大半が料理そのものの
記事(ナポリタン・オムライスなど)。ラーメン以外702件のうち座標を確定できたのは98件
(+誤マッチを引き直した3件)、収録は65件で、**残り557件はOSMに該当POIが無い**
(全国チェーンの企業記事と、閉店・POI未登録の店)。

OSM側から引く経路では、飲食系POI 205,685件のうち`wikipedia`/`wikidata`タグを持つのは
613件(0.3%)しかない。**タグが付くのは有名店だけ**なので、これ自体が知名度のフィルタとして
働く。ただしOSMの`wikipedia`タグは記事の改名に追従しないことがあり
(`ja:梅園 (台東区)`→現在は`梅園 (和菓子店)`)、`ja:`の接頭辞が抜けているものもある。

## ライセンス

- **座標**(`lat`/`lng`列): **全件がOSM由来**で[ODbL](https://opendatacommons.org/licenses/odbl/)。
  まとまった量を再配布する場合は「© OpenStreetMap contributors」の表示と、データベース自体を
  ODbL(または互換ライセンス)で提供することが求められる。一部(55件)はWikipedia(ja)の記事側にも座標が
  あり点検には使ったが、**値はOSMのものに統一している**(Wikipedia側の座標に誤りが2件あったため)
- **説明文**(`description`列): Wikipedia記事の冒頭文由来で
  [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.ja)
- 飲食店を[tourist](../tourist/README.md)に混ぜないのは、**座標が全件ODbLだから**。
  touristは2026-07-23にODbL由来の座標を全件排除してWikipedia + Wikidata由来に統一してあり、
  そこへ飲食店を入れるとtourist側にODbLの表示義務が復活してしまう
