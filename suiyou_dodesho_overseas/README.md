# suiyou_dodesho_overseas(水曜どうでしょう・海外編)

- HTB「水曜どうでしょう」の海外企画の立ち寄り地 **136件** / **15企画** / **29ヵ国** / ルート **15本**
- 出典: jawiki記事「水曜どうでしょうの企画 (海外)」+ 一般知識。座標はNominatim
- **試験データ。立ち寄り順・説明文は一般知識による推定を含み未検証(要確認)**

| ファイル | 内容 |
|---|---|
| `spots.csv` | スポットデータ(136件) |
| `routes.csv` | 企画ごとの旅程(15ルート) |
| `settings.json` | スポット種別の設定(`region_scope`は`"world"`) |

国内企画は[suiyou_dodesho_domestic](../suiyou_dodesho_domestic/README.md)に分けてある。
`region_scope`が`"world"`なので`region`列には国名(日本語)が入り、地域タブ・地名検索・
地図の初回表示が海外向けに切り替わる。

## spots.csv

jawiki記事「水曜どうでしょうの企画 (海外)」に載っている企画の「旅程」節から、明確に特定できる
主要な立ち寄り地のみを抜粋した試験データ(通過しただけの曖昧な地点・詳細不明な地点は対象外)。
収録している企画は、レギュラー放送時(1996年〜2002年)の11本
(オーストラリア大陸縦断3,700キロ・韓国食い道楽サイコロの旅・ヨーロッパ21ヵ国完全制覇・
マレーシアジャングル探検・香港大観光旅行・北極圏突入〜アラスカ半島620マイル〜・
アメリカ合衆国横断・ヨーロッパ・リベンジ・中米コスタリカ・ユーコン川160キロ・
原付ベトナム縦断1800キロ)と、レギュラー終了後の不定期企画4本(ジャングル・リベンジ・
ヨーロッパ20ヵ国完全制覇 完結編・初めてのアフリカ・21年目のヨーロッパ21ヵ国完全制覇)。

座標はchiezo(日本限定)ではカバーできないため、外部のNominatim(OpenStreetMap公式の
地名検索API)を識別可能なUser-Agent・数秒間隔のレート制限付きで直接叩いて取得した
(取り扱いは[../CLAUDE.md](../CLAUDE.md)「外部データソースを扱う際の注意」参照)。

`series`列には企画名が入り、`settings.json`の`series`に企画ごとの色・ラベル(2文字以内の
略称、例: `欧1`)を定義する(国内編と同じ設計)。`categories`列は国内編と同じ理由
(企画数がそのままカテゴリ数になって絞り込みが見づらい)で、**全件`海外企画`の1カテゴリに
統一している**(海外編は行き先がとりとめなく、国内編の`北海道企画`のようなまとまりを
作れないため)。

[buratamori](../buratamori/README.md)・国内編と同様、複数企画で同じ場所を再訪しているケース
(「ヨーロッパ21ヵ国完全制覇」と「ヨーロッパ・リベンジ」で共に凱旋門がスタート地点)は
先に登場した企画の行だけを残し統合済み。`key`列はスポット名(重複なし)で付与。

**具体的な立ち寄り順・説明文は一般知識による推定を含み未検証(要確認)。**

## routes.csv

国内編と同様、jawiki記事の企画ごとの「旅程」節に**書かれている日付順・地名順**をそのまま
`seq`にしたもの。かつてはspots.csvの行順を機械的に`seq`にしていたため、国内編と同じく
出発地や経由地が抜けていた。作り直しで直った主なもの:

- 出発地の欠落: ヨーロッパ・リベンジ(パリ凱旋門から始まるのにザバブルク城が起点になっていた)、
  香港大観光旅行(啓徳空港・中環が無くヴィクトリア・ピークが起点だった)、
  北極圏突入(乗り継ぎ地シアトルが無かった)
- **訪問国そのものの欠落**: ヨーロッパ21ヵ国完全制覇でオーストリア(チロル)を通過している
  のにルートにも`region`にも現れていなかった
- 経由地の欠落: アメリカ合衆国横断の宿泊地(クリントン・バッファロー・マリオン)と
  通過地ナッシュビル、オーストラリア縦断の初日2地点、マレーシアのクアラ・テンベリン、
  ユーコン川のビッグ・サーモン(110km地点)、ベトナム縦断のタインホア・ドンホイ・ダナン・
  クイニョン・ファンラン、ヨーロッパ21ヵ国のフォークストン・ブローニュ・ペルピニャン・
  ブール=マダム

全企画とも経由地2件以上のため全企画がルートを持つ。**旅程節に地名が無い立ち寄り先までは
網羅していない**(マレーシアの動物観察小屋ブンブン・ブラウ、コスタリカの宿など)。また
「ヨーロッパ21ヵ国完全制覇」でモナコ・アンドラに入国したことが本文に書かれているが、
旅程節では経路が特定できないため未収録(要確認)。
