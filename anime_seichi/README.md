# anime_seichi(アニメ聖地)

- アニメ・漫画の聖地 **121件**(点65件 / エリア56件)。40都道府県
- 出典: Wikipedia(ja)の記事「アニメツーリズム協会」の**訪れてみたい日本のアニメ聖地88(2018年度版)** +
  作品記事・自治体記事の舞台/モデル記述。座標はosm_japan・Wikipedia(ja)
- ライセンス: **CC BY-SA 4.0**(説明文)+ **ODbL**(座標)。再配布時は出典表示が必要(→[ライセンス](#ライセンス))
- **全121行に、その行の根拠になったWikipedia(ja)の一文を`evidence.csv`で紐づけてある**

| ファイル | 内容 |
|---|---|
| `spots.csv` | スポットデータ(121件) |
| `evidence.csv` | 全行の根拠(`key,basis,article,sentence,work_pv,spot_pv,coord_source`) |
| `settings.json` | スポット種別の設定(作品別シリーズ67・カテゴリ・ピンの形) |
| `excluded_candidates/supplement_candidates.md` | 補完候補として調べたが収録しなかった作品と理由 |
| `excluded_candidates/exclude.txt` | travel-log側から削除するスポットの`key`一覧(追記式) |

`buratamori`・`suiyou_dodesho_*`が「LLMの記憶」由来で未検証のまま止まっているのに対し、
**この種別はLLMの記憶を一切使っていない**。全行がWikipedia(ja)の原文に紐づいており、
`evidence.csv`と突き合わせれば誰でも検証できる。

## 出典と生成

### 骨格 — 訪れてみたい日本のアニメ聖地88

Wikipedia(ja)の記事「アニメツーリズム協会」の選定地リストを分解した**109行**(作品88・施設19・
イベント2)が母数。表組みが剥がれて連結文字列になっているため、osm_japanの
`place=city`/`town`/`village`から作った自治体名辞書1,891件で末尾を貪欲照合して
`都道府県 / 自治体 / 種別 / 名称`に切り分けた(`むつ市大湊町`・`静岡市清水区`のような
二段の自治体名も復元される)。

**このリストは2018年度版**。記事冒頭に「2019年版から2026年版までの選定地リストの追記」という
要更新テンプレートが貼られており、本文には2018年度版の表しか無い。記事中の出典
(産経2021-12-15)には「アニメ聖地116カ所選定」とあるので現行版とは差がある。
**この差は埋めていない** — 埋めるには協会公式サイトを見に行くことになり、出典がWikipedia(ja)で
閉じなくなるため。

### 点の特定 — 作品記事と自治体記事の両方向

作品ごとに、**作品記事と選定自治体の記事の両方**から`モデル|舞台|ロケ地|ロケハン|取材|
聖地|登場|キービジュアル`を含む文を拾い、地物語を含むものだけを候補にした。

**片方だけでは半分近く取りこぼす。** 『凪のあすから』は作品記事側の候補が0件で、
熊野市の記事に「アニメ製作スタッフ陣が熊野市へ取材におもむき、新鹿海水浴場周辺や
JR紀勢本線の波田須駅などがモデルとして描かれた」があった。逆に『君の名は。』の
須賀神社(新宿区)も自治体側からしか出てこない。

自治体記事には「○○市を舞台とした作品」という一覧節があり、そのまま拾うと**別の作品の
記述が混入する**(武蔵野市の候補にSLAM DUNK・ROOKIESが出た)。そのため自治体側は
**作品名が出現する箇所の前後±2文だけ**を候補にしている。

### 収録の基準

**88選に載っていない作品を足す場合は、次の3条件をすべて満たすこと。**

1. 2018年度版88選に無い
2. Wikipedia(ja)に実在地点または実在自治体の「モデル/舞台」記述がある(作品記事側・自治体記事側のどちらでもよい)
3. **地元自治体・観光協会・作品公式のいずれかが聖地として受け入れている根拠がWikipedia(ja)に書かれている**
   — 町おこし、観光協会主催イベント、公式グッズ販売、駅名標の設置など

条件3を必須にしているのは「ファンがそう呼んでいるだけの場所」を弾くため。ここを緩めると
私有地や、権利者・地元が望んでいない場所まで入ってくる。実際に収録した補完は11件
(→[excluded_candidates/supplement_candidates.md](excluded_candidates/supplement_candidates.md)に
落とした候補の記録がある)。

### 学校は単独スポットにしない

**現役の学校にはピンを立てない。** その学校が属する舞台の地域をスポットにし、
`description`に「作中の○○のモデルは△△学校」と書いて情報だけ残している(3件)。
地図上のピンで校門まで案内しないための措置。

線引きは「閉校したか」ではなく**「現在も学校として使われているか」**で引く。

- **可**: 豊郷町立豊郷小学校の旧校舎群(『けいおん!』) — 現在は町立図書館等が入居する公開施設
- **不可**: 沼津市立長井崎中学校(『ラブライブ!サンシャイン!!』) — 2021年度末で閉校したが
  小中一貫学校に統合されて学校として使われている。沼津市の地域スポットの説明へ吸収した

『おおかみこどもの雨と雪』の「花の家」も、Wikipedia(ja)に「個人宅である」と明記されているため
単独スポットにせず、上市町をエリアとして立てている。

### エリア(点で特定できなかった選定地)

56件。`categories`の2値目に`エリア`が付き、`settings.json`の`category_styles`で
**角丸四角のピン**になる(観光地の`じっくり`と同じ仕組み)。固有名のある湖・地区
(洞爺湖・木崎湖・御手洗地区)も、自治体そのもの(旭川市・大洗町)も同じ扱い。

### イベント2件は除外

`世界コスプレサミット`(名古屋市)・`マチ★アソビ`(徳島市)は開催地が固定でなく、
「訪問した/していない」を記録する対象にならないため落とした。この結果**愛知県は0件**になっている。

## series(作品名)

**シリーズは作品名**。地図のピンの色と絞り込みチップがそのまま作品の区別になり、
チップの一覧が収録作品の一覧を兼ねる。定義は**67シリーズ**(作品66 + 施設1)。

- 並び順は**88選の掲載順**(北海道→沖縄)で作品の初出順。そのあとに選外補完の作品、
  最後に`マンガ・アニメ施設`
- `size`は全シリーズ26で統一(CLAUDE.md「seriesが重要度・段階を表さない種別では
  sizeを全シリーズとも26に統一する」に従う)
- `color`は色相を黄金角(約137.5°)ずつ回して生成。`label`は作品名の頭2文字
  (`ガーリッシュナンバー`と`ガールズ&パンツァー`のように衝突するものだけ手で振り分けた)
- 作品に紐づかない施設20件(石ノ森萬画館・京都国際マンガミュージアムなど)は
  `マンガ・アニメ施設`にまとめてある

### 同じ地点が複数作品の選定地になっている場合

CLAUDE.mdの「1スポット=1行=1シリーズ」に従い、**行は増やさず`series`はシリーズ配列順で
先に来る作品**にし、残りは`description`末尾に「同じ場所が『○○』の聖地としても
選定されている。」と書いている。該当は7件。

| スポット | series | 説明文に回した作品 |
|---|---|---|
| 京都市 | 薄桜鬼 | 少年陰陽師・夜は短し歩けよ乙女・有頂天家族 |
| 千代田区 | 純情ロマンチカ | 世界一初恋・シュタインズ・ゲート |
| 箱根町 | 新世紀エヴァンゲリオン | 弱虫ペダル |
| 武蔵野市 | SHIROBAKO | そにアニ -SUPER SONICO THE ANIMATION- |
| 杉並区 | アクセル・ワールド | アクエリオンロゴス |
| 銀山温泉 | ガーリッシュナンバー | ミス・モノクローム |
| 東京国立博物館 | 時をかける少女 | 刀剣乱舞-ONLINE- |

**この10作品は`settings.json`の`series`に定義していない。** 定義するとどのスポットにも
一致しない空の絞り込みチップができてしまうため。作品名は`description`から拾える。

### ページビューについて(不採用)

当初はtouristと同じA〜Eのページビューランクにしていたが、**絞り込みが5段階にしかならず
収録作品の一覧にならないうえ、地図上で同じ作品か別の作品かが見分けられない**ため取りやめた。
計測した値自体は`evidence.csv`の`work_pv`(作品記事)・`spot_pv`(スポット記事)に残してある。

計測時に分かったこととして、**スポット記事のPVは聖地としての知名度を測れていない** —
`飛騨市図書館`47PV・`御成橋`15PVは実際に巡礼者が来る聖地なのにPVが極小で、逆に`洞爺湖`
3,577PVは聖地と無関係に有名な観光地なので高く出る。`旧秩父橋`に至っては記事が無い。
知名度で並べ直したくなった場合は作品記事のPV(`work_pv`)を使うこと。

## 座標

**Wikipedia(ja)でwikidataのQ番号を得て、それでosm_japanを逆引きする**のが最も精度が高い。
Wikipedia(ja)の座標は丸められていることがあり、鷲宮神社は`36.1, 139.655`だがQ番号経由なら
`36.0999753, 139.6548687`が取れる。解決順は次のとおりで、`coord_source`列に記録してある
(列の値はchiezoのソース名のままなので`osm`=osm_japan・`jawiki`=Wikipedia(ja))。

1. Wikipedia(ja)のQ番号 → osm_japanを`filter?wikidata=`で逆引き
2. Wikipedia(ja)の`extra.lat/lon`
3. osm_japanの名前一致
4. osm_japanの名前検索(**誤バインドするため要目視**)

4段目は実際に間違えた。`御手洗`の検索が「御手洗昭和館」を、`静岡市清水区`が「清水区蒲原支所」を
返しており、いずれも座標が近いので気づきにくい。どちらも手で直してある。
`coord_source`に`※要目視`が付いた5件は、名前検索の結果をそのまま採用しているので
再点検の対象。

**`name`はosm_japan/Wikipedia(ja)のタイトルを採用しているが、そのままでは使えない場合がある。**

- **osm_japanの駅は名称に「駅」を含まない**(`一乗寺`・`西宮北口`)。`○○駅`に統一している
- **併設・隣接する別の地物の名前に化ける**ことがある。`ちびまる子ちゃんランド`が
  「エスパルスドリームプラザ」(入居先の商業施設)、`水木しげるロード`が「水木しげる記念館」、
  `ウルトラマン商店街`が「祖師ヶ谷大蔵」(最寄り駅)になっていた。座標は正しいので名称だけ戻した
- 逆に**OSM側のほうが正しい**ケースもある。`豊郷町立豊郷小学校`→`豊郷小学校旧校舎群`、
  `仙台市八木山動物公園`→`八木山動物公園 フジサキの杜`(現行の正式名称)はOSM側を採用した

## 既知の限界

- **88選が2018年度版**であること(前述)。現行版との差は埋めていない
- **未収録の県が7つある**: 和歌山県・宮崎県・山口県・島根県・福井県・群馬県(88選に元から無い)と
  愛知県(イベントのみのため除外)。補完で滋賀県(けいおん!)と山梨県(ゆるキャン△)は埋めた
- **エリアが56件(46%)を占める**。都市部の作品(『純情ロマンチカ』『世界一初恋』
  『シュタインズ・ゲート』など千代田区の各作品)はWikipedia(ja)に具体地点が書かれておらず、
  自治体の代表点しか置けていない
- **有名な聖地ほどWikipedia(ja)に「どこ」が書かれていない**傾向がある。『ガールズ&パンツァー』(大洗町)は
  記事が町おこしの経緯と作品論で埋まっており具体地点が0件だった。同様に
  『艦隊これくしょん -艦これ-』の5件(大湊・横須賀・舞鶴・呉・佐世保)もすべてエリア止まり
- `spots.csv`の`name_kana`は全行空欄(五十音ソートは効かない)

  121件を1件ずつ引いた形であっても適用する
