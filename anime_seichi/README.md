# anime_seichi(アニメ聖地)

- アニメの聖地 **498件**(点242件 / エリア256件)。40都道府県・**337シリーズ**
- 出所は2系統 — アニメツーリズム協会の**現行の選定地172件**と、
  Wikipedia(ja)の舞台カテゴリ由来の**326件**。`categories`で見分けられる
- 実際のデータ(名称・座標・説明文)はすべてWikipedia(ja)とOpenStreetMapから取っている
  (協会からは選定地の名称しか取得していない)
- ライセンス: **CC BY-SA 4.0**(説明文)+ **ODbL**(座標)。再配布時は出典表示が必要(→[ライセンス](#ライセンス))
- **根拠は`evidence.csv`に紐づけてある**(330行ぶん。エリア行を1作品1行へ分解した際に
  増えた行は、分解元の行の根拠をそのまま引き継ぐため個別の行を持たない)

| ファイル | 内容 |
|---|---|
| `spots.csv` | スポットデータ(498件) |
| `evidence.csv` | 行の根拠(`key,source,basis,place,article,sentence,coord_source,merged_series`)。`merged_series`は**1作品1行へ分解する前にその代表点へ畳んでいた作品の記録**で、いまの行の内容ではない |
| `settings.json` | スポット種別の設定(ランクの有効化・作品別シリーズ337・カテゴリ2種) |
| `excluded_candidates/supplement_candidates.md` | 収録しなかった作品・地点と理由 |
| `excluded_candidates/exclude.txt` | travel-log側から削除するスポットの`key`一覧(追記式) |

`buratamori`・`suiyou_dodesho_*`が「LLMの記憶」由来で未検証のまま止まっているのに対し、
**この種別はLLMの記憶を一切使っていない**。全行が出典に紐づいており、`evidence.csv`と
突き合わせれば検証できる。

## 出典と生成

### 出所は2系統

| `categories` | 件数 | 何か |
|---|---|---|
| `公式選定` | 172 | アニメツーリズム協会「訪れてみたい日本のアニメ聖地88」の現行の選定地 |
| `Wikipedia由来` | 326 | Wikipedia(ja)の「○○を舞台とした{アニメ,漫画}作品」カテゴリから足した分 |

協会の選定は「聖地として公認されている」線引きだが、**網羅ではない**
(『ちはやふる』の近江神宮、『こちら葛飾区亀有公園前派出所』の葛飾区などが入らない)。
そのためWikipedia(ja)のカテゴリから辿れるものを足した。両方に該当する作品は
`公式選定`側を優先している(20作品)。

絞り込みチップで`公式選定`だけを見れば、協会の選定地だけを辿れる。

### 母数 — アニメツーリズム協会の現行の選定地(名称のみ)

「訪れてみたい日本のアニメ聖地88」の選定地は、協会サイトの**公式WordPress REST API**で
公開されている(HTMLのスクレイピングは不要)。

```
GET https://animetourism88.com/wp-json/wp/v2/places?sites_cat=<日本語カテゴリのID>
```

日本語版の**175件**(作品145・施設28・番札所2)を取得し、**117のユニークな記事**に解決した。
取得したのは**タイトル(選定地の名称)だけ**で、協会側の紹介文・写真・座標・所在地は
1件も取り込んでいない(→[ライセンス](#ライセンス))。所在地・座標・説明文はすべて
Wikipedia(ja)とOpenStreetMapから取り直している。

かつてはWikipedia(ja)記事「アニメツーリズム協会」に載っている選定地リストを使っていたが、
**あの記事は2018年度版で止まっている**(要更新テンプレートが貼られたまま)。現行版との差が
大きいため、母数だけを公式APIに切り替えた。

### 点の特定 — 作品記事と自治体記事の両方向

作品ごとに、**作品記事と、その作品の舞台カテゴリが指す自治体・都道府県の記事**の両方から
`モデル|舞台|ロケ地|ロケハン|取材|キービジュアル`を含む文を拾い、地物を表す語を含むものだけを
候補にした。所在地は協会からではなく、Wikipedia(ja)の**「○○を舞台とした作品」系のカテゴリ**から
割り出している。

**この系統には接尾辞の違う体系が複数ある。**「○○県を舞台としたアニメ作品」のほかに
**種別を付けない「○○市を舞台とした作品」**があり、後者のほうが市区町村まで細かい
(68タグ・延べ825件)。接尾辞を列挙して照合すると後者を丸ごと落とすため、
**「を舞台とした」の前を自治体名の辞書と突き合わせる**方式にしてある。
「東京都中央区を舞台とした作品」のように県名が前置される形もあるので、
前置された県名は落としてから照合する。

**市区町村のカテゴリが複数ある作品は、その数だけ行を作る。**
『ラブライブ!サンシャイン!!』は沼津市(TVシリーズ)と函館市(劇場版)の2行になる。
公式リスト側も同作を2件で登録しているので、実態に合う。

**舞台カテゴリが県どまりのときは、2018年度版の選定地リストで自治体まで補う。**
「○○町を舞台としたアニメ作品」というカテゴリは大半の町村に存在せず
(`大洗町`にも無い)、カテゴリだけで決めると『ガールズ&パンツァー』が
大洗町ではなく茨城県になってしまう。旧リストは自治体まで持っているので、
**県が一致する場合に限り**そちらを採る(該当5件)。県が食い違う場合は上書きしない —
『弱虫ペダル』はカテゴリが千葉県、旧リストが神奈川県箱根町で、どちらが現行の
選定地なのか判断できないため、カテゴリ側の千葉県のままにしてある。

旧リストにも無い場合は、**作品記事の本文から舞台の自治体名を拾う**
(`舞台|モデル|ロケハン|取材`を含む文に出てくる市区町村名のうち、その県に属し
最も多く出現するもの)。これで6件が県から自治体へ寄った(`前橋ウィッチーズ`→前橋市、
`負けヒロインが多すぎる!`→豊橋市、`やくならマグカップも`→多治見市 ほか)。
**それでも21件は県の代表点のまま**で、これは記事が自治体名を書いていないため。

自治体記事には「○○市を舞台とした作品」という一覧節があり、そのまま拾うと**別の作品の
記述が混入する**(武蔵野市の候補にSLAM DUNK・ROOKIESが出た)。そのため自治体側は
**作品名が出現する箇所の前後±2文だけ**を候補にしている。

「モデル」は多義語で、機械抽出だけでは決められない。実際に出た誤検出は
`カモガワ・モデル`(作中の機体名)・`新井康之がモデル`(人物)・`プラモデル`など。
採否はすべて目視で判断した。

### Wikipedia由来の115件 — 3段の絞り込みを掛けている

「○○を舞台とした{アニメ,漫画}作品」カテゴリに属するのは**1,780作品**あるが、
次の3段で41行まで絞り、そこから下記の2つの軸で点を起こして115行になっている
(内部リンク: エリア行から12件・畳まれた作品から43件 / 「聖地」節: 19件)。

1. **市区町村まで分かるものだけ**(641作品)。県しか分からない1,139作品は入れない —
   入れると47か所の県庁所在地に最大156件(東京都)が重なり、訪問先として意味を成さない
2. **実際にアニメ化されている作品だけ**(621→287作品)。カテゴリには
   「その自治体が舞台の漫画・小説だがアニメ化はされていない」作品が多く含まれ、
   ページビューで代表を選ぶと会津若松市が『八重の桜』(大河ドラマ)、鎌倉市が
   『海街diary』(実写映画)になってしまう。

   判定は**記事のカテゴリと本文の両方**を見る。カテゴリ(`テレビアニメ`・`アニメ映画`・
   `OVA`等)だけでは足りない — **漫画とアニメで記事が分かれている作品は、舞台カテゴリが
   付いている漫画側の記事にアニメ系カテゴリが無い**ためで、『こちら葛飾区亀有公園前派出所』
   『サザエさん』『キン肉マン』のような明確なアニメ作品を24件取りこぼしていた。
   本文に「テレビアニメ化」「アニメ化され」「テレビアニメ…が放送」のような
   アニメ化の事実を述べる記述があれば通す
3. **同じ地点に複数ある場合は、月次ページビューが最大の作品だけを残す**。
   残りは説明文に「同じ地点が『○○』の舞台としても記録されている。」と書き、
   全件を`evidence.csv`の`merged_series`列に残す
   (CLAUDE.md「1スポット=1行=1シリーズ」に従う)

**畳むのはエリア行だけで、点スポットは重なっていてもそのまま残す。**
点は「その場所そのもの」を指しており、別の作品の聖地が同じ場所にあること自体に
意味があるため。積み上がりは最大79件から**最大4件**(21地点)まで減った。

### 記事に「聖地」節がある作品は、そこから点を起こす

**候補文の抽出は`モデル|舞台|ロケ地|ロケハン|取材|キービジュアル`を含む文しか見ないので、
「○○として登場する」だけで書かれた地点を丸ごと落とす**。実例が
『ガールズバンドクライ』で、記事には**「聖地」という節があって12か所を列挙している**のに、
どの文にも上のどの語も出てこないため候補が0件になり、川崎市のエリア行1件で止まっていた。

そこで記事に「聖地」「舞台となった場所」のような列挙の節がある作品は、
節そのものを読んで点を起こす(『ガールズバンドクライ』は12か所のうち8か所)。
`evidence.csv`の`basis`は`登場`になる。

**走査はスポットに出ている作品だけでは足りない。** `merged_series`に畳まれている作品は
`series`列に現れないので、スポット側だけを見ると素通りする。全363作品(スポット139 +
畳まれたまま224)の記事を走査したところ17件が該当し、そのうち`うさぎドロップ`・
`デジモンセイバーズ`・`デジモンフロンティア`の3件は**畳まれたままだった** —
節を読めば点が起こせる作品が、代表点の下に隠れていたことになる。
点が起きた作品は畳みから独立させ、受け皿の行の`merged_series`と説明文から外す。

節の見出しだけでは判断できないものも多い。`制作背景`・`背景美術`のような無関係な節を
落としたうえで、中身が**地点の列挙になっているか**を見る(『ゆるキャン△』の
「音楽祭・聖地イベント」はイベント一覧、『聖☆おにいさん』の「聖地巡礼②」は各話タイトル、
『らき☆すた』の節は町おこしの経緯で、いずれも新しい地点は出てこない)。
採用したのは9作品39件で、内訳は`STEINS;GATE`6・`デジモンアドベンチャー`8・
`八十亀ちゃんかんさつにっき`9・`デジモンセイバーズ`4・`前橋ウィッチーズ`3・
`竜とそばかすの姫`3・`うさぎドロップ`2・`デジモンフロンティア`2・
`ハチミツとクローバー`2。**商品名・企業名・番組名・学校は落としてある**
(『八十亀ちゃん』の節は実在の商品と建物が混在した名前の羅列で、地物だけを拾った)。

**同じ施設の中の複数の地点は1行にまとめる。** 座標が同じになるぶんピンが重なるだけで、
訪問先としては1か所だから(ラゾーナ川崎プラザは第3話のルーファ広場と第4話の島村楽器の
2か所が挙がっているが、`ガールズバンドクライ(ラゾーナ川崎プラザ)`の1行にして、
両方を`description`に書いている)。8か所が7行になっているのはこのため。


### 既知の取りこぼし — 県・地域レベルの舞台カテゴリは行にならない

上の「市区町村のカテゴリが複数ある作品は、その数だけ行を作る」は、裏を返すと
**市区町村レベルでないカテゴリ(`東京を舞台とした`・`神奈川県を舞台とした`・
`湘南を舞台とした`)は、市区町村のカテゴリを1つでも持つ作品では丸ごと落ちる**。
落ちた側に代表点すら作られないので、**その県の聖地が1件も無い作品**ができる。

実例が『SLAM DUNK』で、カテゴリは `神奈川県` `湘南` `広島市` の3つあるのに、
市区町村レベルなのが広島市だけだったため**広島市の代表点1行しか無かった**
(2026-08-12に鎌倉高校前1号踏切を点として追加した)。

全337シリーズのカテゴリを都道府県に解決して収録済みの行と突き合わせると、
**38作品・50組(作品×都道府県)**が同じ形で抜けている。抜けている県は東京都が17件と
突出していて、これは`東京を舞台とした`が市区町村レベルでないことがそのまま出たもの。

**この一覧は候補であって確定した漏れではない。** 収録するには、この種別の方針どおり
作品記事の本文に モデル/舞台/ロケ地/登場 を述べた文があるかを1件ずつ確認する必要があり、
`東京を舞台とした`・`江戸を舞台とした`のようにそもそも点にできないものも混ざっている。
実際、この調査から採ったのは次の3件だけで、『MFゴースト』の静岡県(本文の熱海の記述は
『金色夜叉』の話)や『秘密結社鷹の爪』の島根県(PR大使・イベントの話)は根拠にならず落とした。

| 作品 | 追加した地点 | 根拠 |
|---|---|---|
| ゆるキャン△ | 浩庵キャンプ場(山梨県) | 「本栖センターロッジ」のモデル |
| お〜い!竜馬 | 高知市(代表点) | カテゴリ`高知市を舞台とした作品`。既存の京都市・長崎市と同じ扱い |
| 秒速5センチメートル | 中種子町(代表点) | 第2話の舞台。作中店舗のモデル店は記事に店名の明記が無い |

### 記事の内部リンクから点を起こす

**本文の語で拾う方式は「その語を使って書かれた記事」しか拾えない**。そこで語ではなく
**記事が張っている内部リンク**を候補の源にする軸を足した。エリア113件の記事から
延べ28,858本(ユニーク17,574本)のリンクを引き、そのうち**座標を持つ1,267記事**を、
代表点から15km(県の代表点は30km)以内・カテゴリが地物を表すもの(`駅`・`橋`・`神社`・
`建築物`など)だけに絞ると59作品・361件になる。

**ここまでは候補でしかない**。「リンクされていて近い」は聖地の根拠にならず、実際
『こちら葛飾区亀有公園前派出所』の候補には浅草神社と銀座が並んだ(巻末コメント一覧表からの
誤マッチ)。そこで**候補ごとに作品記事の本文へ戻り、その地点名を含む文のうち
モデル/舞台/ロケ地/登場/描かれ/実在を述べているものだけ**を残した(33作品75件)。
残った文がそのまま`evidence.csv`の`sentence`になる。

そのうえで目視で36件を採用した。落としたものの理由:

- **根拠記事が自治体記事だと他作品の文が混入する** — 『とある魔術の禁書目録』の
  `article`は立川市で、候補の根拠文は『フレームアームズ・ガール』等の別作品のものだった
- **コラボイベント・舞台挨拶・先行上映の会場** — 作品と縁はあるが作中の場所ではない
  (『竜とそばかすの姫』のTOHOシネマズ、『ヤマノススメ』の西武ドームなど)
- **部分文字列の誤マッチ** — 「秩父駅」が「西武秩父駅」を含む文に一致した
- **現役の学校**(当時の方針。→[学校は注意書きを添えて収録する](#学校は注意書きを添えて収録する))

この軸で起こした点は**Wikipedia由来としては初めての点スポット**で、説明文の末尾に
`(出典: ja.wikipedia のカテゴリ)`は付けない — カテゴリではなく本文が根拠だから。

**この軸も、畳まれている作品まで回さないと半分しか見ていない。** エリア行だけを対象に
した1回目は22作品36件だったが、`merged_series`に畳まれた224作品にも同じ手を回すと
40作品74件の候補が残り、**27作品47件を採用した**(基準点は、その作品が畳まれている
行の代表点を使う)。伏見稲荷大社(『いなり、こんこん、恋いろは。』)・艮神社と御袖天満宮
(『かみちゅ!』)・小田原城(『カイチュー!』)のように、**代表点の下に隠れていた分の
ほうが多い**。落としたのは、コラボの等身大パネル設置駅(『いなり、こんこん、恋いろは。』)、
取材協力のクレジット(『模型戦士ガンプラビルダーズ』)、`Category:` 行だけが根拠のもの
(『魔法遣いに大切なこと』の下北沢)、現存しない建物(『あぶさん』の大阪スタヂアム)、
記事が「作中に登場しない」と明記しているもの(『イエスタデイをうたって』の葵橋駅)など。

**同じ系列の作品は既存のシリーズに寄せる。**『涼宮ハルヒの憂鬱』の4件は
新しいシリーズを作らず`涼宮ハルヒシリーズ`に足した(同じ西宮市に既に2件あるため)。

### エリア行は、作品記事を読み直して点に落とす

**ランクが上のものほどピンが大きい**(→[ランク](#ランク作品の知名度))ので、そこが自治体の
代表点のままだと、地図の一番目立つところに「どこへ行けばいいのか分からない大きな丸」が
残る。そこで**ランクの高い順に**、機械抽出の候補文ではなく**作品記事の本文を読み直し**、
点になるものを起こした。**歩留まりはランクが下がるほど落ちる**(A:13件中8件 /
B:38件中11件 / C:87件中5件 / D:87件中3件 / E:60件中3件)。ランクが下がるほど記事が短く、
「○○市が舞台」で終わっているものが増えるため。

| 作品 | 起こした点 | 根拠になった記述 |
|---|---|---|
| ちびまる子ちゃん | 清水入江小学校 | 「まる子たちが通う入江小学校も、実在する学校である」 |
| リコリス・リコイル | 錦糸町駅 | 「喫茶リコリコ」は「錦糸町駅北口から少し歩いた墨田区内の下町に所在し」 |
| 超かぐや姫! | 立川シネマシティ | 「作中の舞台にもなった立川シネマシティ」 |
| ガラスの仮面 | 横浜中華街 | マヤの母は「横浜中華街の中華料理店『万福軒』の住み込み店員」 |
| 新世紀エヴァンゲリオン | 芦ノ湖 | 「第3新東京市とは…箱根町仙石原付近の芦ノ湖北岸あたりになる」 |

### `name`は作品名、場所は説明文の先頭

**1つの作品が各地に複数のスポットを持つ**ため、`name`には**作品名**を入れ、
場所の名前は`description`の先頭に置いている(`金泉湯(東京都)。『BanG Dream!』の舞台の
モデルとされる。…`)。地図のピン・一覧のラベルが作品名になるので、どの作品の聖地かが
ひと目で分かる。

**同じ県に同じ作品のスポットが2件以上あるときだけ**、`name`の末尾に場所名を足して
区別する(`ひぐらしのなく頃に(白川郷)`・`ひぐらしのなく頃に(白川八幡神社)`)。
1件だけの作品は作品名そのままなので、大半の行はWikipedia(ja)の記事名と完全一致する。

施設(石ノ森萬画館など)は場所そのものが主役のため、`name`も施設名のままにしている。

**`name`が重なるときは`key`側を`_2`・`_3`で外す**(接尾辞のルールは県ごとなので、県をまたいで1件ずつ持つ作品は同じ`name`になる)。`ラブライブ!サンシャイン!!`(北海道・静岡県)、`ハチミツとクローバー`(東京都・神奈川県・群馬県)がこれにあたる。

### `settings.json`の`wikipedia_title_source`

`"wikipedia_title_source": "series"` を指定してある。スポット詳細のWikipediaリンクが
**スポット名ではなくシリーズ名(=作品名)の記事**を開く設定(travel-log側の
`lib/region.ts`の`resolveWikipediaTitleSource`)。`name`に場所名の接尾辞が付いた行でも、
シリーズ名は接尾辞なしなので記事が確実に引ける。

シリーズ名の記事が無い行(施設の`マンガ・アニメ施設`など)は、travel-log側が自動的に
スポット名での検索にフォールバックする。

## series(作品名)

**シリーズは作品名**で、165シリーズ(作品164 + `マンガ・アニメ施設`)。地図のピンの色と
絞り込みチップがそのまま作品の区別になり、チップの一覧が収録作品の一覧を兼ねる。

- 並び順は作品名順で、`マンガ・アニメ施設`のあとに**後から足した分を追記している**
  (色が並び順から決まるため、間に挿入すると以降の色が全部ずれる)
- `size`は全シリーズ26で統一(CLAUDE.md「seriesが重要度・段階を表さない種別では
  sizeを全シリーズとも26に統一する」に従う)
- `color`は色相を黄金角(約137.5°)ずつ回して生成(`i`番目の色相 = `i × 137.5°`)。
  `label`は作品名の頭2文字で、衝突したら`2`を足す(`ラブ`→`ラブ2`→`ラブ22`)
- **定義しているシリーズは実際に使われているものだけ**。使わないシリーズを定義すると、
  どのスポットにも一致しない空の絞り込みチップができるため

## ランク(作品の知名度)

**2026-08-11に有効化**。他の種別と違い、ランクの根拠は**スポットではなく作品**
(シリーズ)のWikipedia(ja)記事の月次ページビュー(bot除外)。聖地は「どの作品の
舞台か」で価値が決まり、エリア指定の行にはスポット自体の記事が無いため。
区分は他の種別と同じ A上位5% / B次15% / C次30% / D次30% / E残り20%(337作品中):

| ランク | 作品数 | 月次ページビュー |
|---|---|---|
| A | 17 | 27,654〜70,160 |
| B | 51 | 12,204〜27,581 |
| C | 100 | 4,230〜12,108 |
| D | 101 | 1,218〜4,188 |
| E | 67 | 53〜1,212 |

**同じ作品のスポットは同じランク**になる(スポット数では A34 / B92 / C151 / D127 / E67)。
記事が引けなかった`マンガ・アニメ施設`の23件はランクなし。

**色はランクではなくシリーズ(作品)のまま**。travel-log側は
「シリーズに色の指定があればそれを優先し、無ければランクの色」という規則なので、
ランクを有効にしても作品ごとの色分けは変わらず、**変わるのはピンの大きさだけ**。

## エリア(点で特定できなかった選定地)

254件(全体の51%)。`categories`に**`エリア指定`**が付く(点で特定できたものは
**`スポット指定`**。2026-08-11に、この2種類で全件を分けた)。**かつては`category_styles`で
角丸四角のピンにしていた**が、ピンの形はシリーズ(作品)側の設定へ移り、
カテゴリは見た目を持たなくなったため、いまは絞り込みの目印としてだけ効く。
出どころの`公式選定`(アニメツーリズム協会88選)・`Wikipedia由来`はそのまま残してある。

**同じ地点にまとめていた作品は、2026-08-11に1作品1行へ分解した**(188行を追加し、
272件→460件)。それまでは「1スポット=1行=1シリーズ」の規則に従い、同じ代表点に
なる作品は先に登場した1行にまとめ、残りを説明文へ追記していた —— そのため
**作品で絞り込むと出てこない聖地**があった。分解した行の出どころは`Wikipedia由来`に
そろえてある(親の`公式選定`は親の作品についての区分のため)。同じ座標に複数の
ピンが立つが、travel-log側は重なりを「+N」バッジと一覧で扱える。

エリア行は自治体・都道府県の代表点に置くため、**同じ座標に複数のスポットが重なる**。
travel-log側はこれに対応していて、重なったピンには「+N」バッジが出て、タップすると
「この地点のスポット」一覧からどれを開くか選べる。

## 座標

**Wikipedia(ja)でwikidataのQ番号を得て、それでOpenStreetMapの地物を逆引きする**のが
最も精度が高い。
Wikipedia(ja)の座標は丸められていることがあり、鷲宮神社は`36.1, 139.655`だがQ番号経由なら
`36.0999753, 139.6548687`が取れる。解決順は`coord_source`列に記録してある。

1. Wikipedia(ja)のQ番号 → 同じQ番号を持つOpenStreetMapの地物を逆引き
2. Wikipedia(ja)の`extra.lat/lon`
3. OpenStreetMapの名前一致
4. OpenStreetMapの名前検索(**誤バインドするため要目視**)
5. 入居先の施設の座標(**商業施設の中の店舗だけの最後の手段**)

**商業施設の中の個別の店舗は、どちらのソースにも地物が無いことが多い**。
その場合だけ入居先の施設の座標を使い、`coord_source`に`入居先`と書いて、
`description`にも「座標は店舗ではなく入居先の○○のもの」と明記する
(『ガールズバンドクライ』のヒルバレー ラ チッタデッラ店・丸福珈琲店 川崎アゼリア店の2件)。
ずれは50〜150mで、施設まで辿り着けば店には行ける。
入居先そのものに地物が無いときは、それと直結する地物まで代用してよい
(川崎アゼリアは川崎駅東口の地下街なので、川崎駅の座標を使っている)。

**代用は「歩いて同じ場所に着く」範囲まで**。どの建物か分からない店舗を駅や市の代表点に
置くと、点スポットが実質エリアになる。そこまで来たら収録を見送り、
[supplement_candidates.md](excluded_candidates/supplement_candidates.md)に記録する。

**`name`はOpenStreetMap/Wikipedia(ja)のタイトルを採用しているが、そのままでは使えない場合がある。**

- **OpenStreetMapの駅は名称に「駅」を含まない**(`横瀬`・`西宮北口`)。`○○駅`に統一している
- **併設・隣接する別の地物の名前に化ける**ことがある。`ちびまる子ちゃんランド`が
  「エスパルスドリームプラザ」(入居先の商業施設)、`水木しげるロード`が「水木しげる記念館」に
  なっていた。座標は正しいので名称だけ戻した
- **札所番号・山号で飾られる**ことがある(`大慈寺`→「秩父10番 萬松山 大慈寺」)。
  元の名称のほうが短く通りが良いため、そちらを採る
- **無関係な地物を返すことがある。** `東京都中央区`で引いた『江戸前エルフ』が
  「中央湊郵便局」になっていた(座標も郵便局のもの)。作中の舞台である月島を
  代表点に変えた。`coord_source`に`※要目視`が付いた行は必ず中身を見ること

  『ガールズバンドクライ』の4件がこれにあたる(→
  [supplement_candidates.md](excluded_candidates/supplement_candidates.md))
- **エリアが254件(51%)を占める**。都市部・広域が舞台の作品はWikipedia(ja)に具体地点が
  書かれておらず、自治体の代表点しか置けていない。うち**21件は自治体すら特定できず、
  県の代表点**に置いてある(同じ県の複数作品が同一座標に重なる)
- **有名な聖地ほどWikipedia(ja)に「どこ」が書かれていない**傾向がある。
  『ガールズ&パンツァー』(大洗町)は記事が町おこしの経緯と作品論で埋まっており
  具体地点が0件だった
- **「○○区を舞台とした作品」カテゴリの区名が、同名の別の区に当たっていた**(2026-08-11に修正)。
  カテゴリ名から前置された都道府県名を落としてから自治体名の辞書と突き合わせる方式のため、
  「東京都中央区」が札幌市中央区に、「東京都港区」が名古屋市港区に当たり、9件が別の県に
  置かれていた。**記事のカテゴリには都道府県が前置された形が残っている**ので、
  そこと`region`が食い違う行として機械的に洗い出せる(→
  [supplement_candidates.md](excluded_candidates/supplement_candidates.md))。
  同名の区がある自治体名は、都道府県まで込みで照合しないと決まらない。
  `大奥_3`(北海道)と`バブル`(愛知県)はシリーズ名の記事(`大奥`・`バブル`)が曖昧さ回避で
  舞台カテゴリを持たないため一度は保留したが、`description`が指している実際の記事
  (`大奥 (漫画)`・`バブル (2022年の映画)`)を見れば同じ取り違えと分かり、
  こちらも直した(**照合はシリーズ名ではなく`description`の出典記事名で行う**)
- **同じ都道府県に`name`が同じ行が並んでいた作品7つを直した**(2026-08-11)。
  6作品(`恋は雨上がりのように`・`おぼっちゃまくん`・`ど根性ガエル`・`一休さん`・
  `ヨコハマ買い出し紀行`・`幻魔大戦`)は自治体名の接尾辞を足し、
  `とある魔術の禁書目録`は**同じ立川市の同じ座標に公式選定とWikipedia由来の行が
  二重にあった**ため、Wikipedia由来の行を削除した(両方に該当する作品は公式選定を
  優先する規則どおり。`exclude.txt`に追記済み)
- `spots.csv`の`name_kana`は全行空欄(五十音ソートは効かない)

## 学校は注意書きを添えて収録する

**学校もスポットにする。ただし`description`の末尾に必ず
「現役の学校のため、敷地内には立ち入らず外観のみ。」を入れる**(現役でないものには入れない)。
2026-08-11に方針を変えたもので、それまでは**現役の学校にはピンを立てず**、その学校が
属する地域のスポットの`description`に「作中の○○のモデルは△△学校」と書いて
情報だけ残していた。

**変えた理由は、避けても目的を果たしていなかったから。** 学校名は説明文に書いてあり、
名前で検索すれば場所は分かるので「知られない」効果は最初から無い。一方で
**座標をわざと不正確にする**副作用があり、『青春ブタ野郎シリーズ』はモデルの大学から
400m離れた金沢八景駅にピンを置いていた。学校しか具体地点が無い作品
(『おおきく振りかぶって』『ハチミツとクローバー』『日々は過ぎれど飯うまし』)が、
その理由だけで自治体の代表点に留まってもいた。

**代わりに、ピンを置く側が扱い方も一緒に書く。** ピンは事実ではなく行き先として読まれ、
スポット詳細からはGoogle マップの経路検索が1タップで引ける —— 百科事典の記述より
一歩進んで導線を作ることになるので、注意書きは省かない。協会自身も
「アニメ聖地訪問マナーに関するお願い」を出している。

現役かどうかの線引きは「閉校したか」ではなく「**現在も学校として使われているか**」。
閉校しても統廃合で別の学校になった校舎は学校のまま扱う。

**私有地・個人宅は引き続き収録しない。** こちらは「そこが聖地」ではなく住んでいる人の
住所そのもので、公開された事実かどうかとは別の問題だから(『サマーウォーズ』の陣内家の
モデルになった住宅がこれにあたる)。

**ただし、所有者が一般公開しているものは私有地扱いにしない。**
『おおかみこどもの雨と雪』の「花の家」は個人所有の古民家だが、記事には
「NPO法人『おおかみこどもの花の家』により公開されている」「基本的に日中は見学可能」と
あり、かつて「個人宅と明記されている」を理由に外していたのは記事の読み落としだった
(いまは座標が引けないため見送っている。→
[supplement_candidates.md](excluded_candidates/supplement_candidates.md))。

## 出典記事のURL(`description`末尾)

`description`が元から持っていた`(出典: ja.wikipedia「XXX」)`に、記事のURLを足してある
(469件)。`(出典: アニメツーリズム協会)`の29件は**Wikipedia由来ではない**ので足していない
(協会からは選定地の名称しか取っていない。→[出典と生成](#出典と生成))。

記事名は説明文が持っていたものをそのまま使うので、`evidence.csv`の`article`とは別に
持っている行(エリアを1作品1行へ分解して増えた行)にも付く。

URLの記事名は、**空白を`_`に、丸括弧を`%28`/`%29`に置き換える**。travel-log 側は
説明文中のURLを「空白か括弧が出たら終わり」で切ってリンクにするため
(`components/LinkedText.tsx`)、生の括弧を残すと行き先が欠ける。
日本語はそのまま置く(パーセントエンコードすると1文字9桁になり読めなくなる)。

## ライセンス

- **説明文** — Wikipedia(ja)由来 → **CC BY-SA 4.0**。百科事典の文をそのまま流用せず、
  「モデル/舞台/取材/エリア」の文型に要約して書き直してある。根拠となった原文は
  `evidence.csv`側に、引用元記事名(`article`列)とともに残している
- **座標** — OpenStreetMap由来 → **ODbL**。
  再配布時は出典表示が必要。CLAUDE.mdの「OSM由来の座標には取り方によらずODbLの
  表示義務を付ける」に従う
- **アニメツーリズム協会のデータ** — **取り込んでいない。**
  協会サイトには利用規約のページが無く(プライバシーポリシーのみで、著作権・転載・
  二次利用のいずれの条項も無い)、明示的な利用許諾が存在しない。88か所を「選定」する
  行為は選択・配列にあたるため、リストは編集著作物として保護されうる。そのため
  CLAUDE.mdの「条件の合わないデータはヒントとして使うにとどめ、実際に配布するデータは
  ライセンス上問題のないソースから取り直す」に従い、
  **APIから取ったのは選定地の名称だけ**にとどめ、`spots.csv`に入っている名称・座標・
  説明文はすべてWikipedia(ja)/OpenStreetMap由来のものに置き換えてある。
  `description`末尾の「アニメツーリズム協会『訪れてみたい日本のアニメ聖地88』の現行の
  選定地。」は事実の記載と出典表示である
- 作品名・キャラクター名は商標・著作権の対象。`description`に作中設定を長く引用していない
