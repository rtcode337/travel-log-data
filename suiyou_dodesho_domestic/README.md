# suiyou_dodesho_domestic(水曜どうでしょう・国内編)

- HTB「水曜どうでしょう」の国内企画の立ち寄り地 **279件** / **39企画** / ルート **34本**
- 出典: jawiki記事「水曜どうでしょうの企画 (日本国内)」+ 一般知識。座標はosm_japan・Nominatim
- **試験データ。スポットの採否・説明文・各企画との対応関係は未検証(要確認)**

| ファイル | 内容 |
|---|---|
| `spots.csv` | スポットデータ(279件) |
| `routes.csv` | 企画ごとの行程(34ルート・327行) |
| `settings.json` | スポット種別の設定(企画ごとの色・略称ラベル) |
| `excluded_candidates/exclude.txt` | travel-log側から削除するスポットの`key`一覧(追記式) |

海外企画は[suiyou_dodesho_overseas](../suiyou_dodesho_overseas/README.md)に分けてある。
`suiyou_dodesho_domestic`という国内限定であることが分かるキー名にしているのはそのため
(海外編は`region_scope`が`"world"`で`region`列に国名が入るので、同じ種別には混ぜられない)。

## spots.csv

jawiki記事「水曜どうでしょうの企画 (日本国内)」の本文から、企画中に立ち寄った・通過した
地点を一般知識で抽出した試験データ。観光名所に限らず、サイコロの目で決まっただけの経由地・
宿泊地・道の駅・サービスエリア・フェリー乗り場なども対象に含む(地名が特定できない曖昧な
記述のみ対象外)。レギュラー放送時(1996年〜2002年)の企画に加え、レギュラー終了後の
不定期企画5本(プチ復活!思い出のロケ地を訪ねる小さな旅・激闘!西表島・原付日本列島制覇・
北海道で家、建てます・懐かしの西表島)も収録している。

座標はosm_japanで裏取りするが、**osm_japan(chiezo)には鉄道駅・空港・港・IC/SAが
入っていない**ため、それらはNominatimで取得している。市町村・字・廃業済みの施設など点で
特定できないものは自治体や近隣地物の代表点で代用し、その旨を`description`末尾に書いてある
(例: 上発知のしだれ桜=沼田市上発知町の代表点、HTB=企画当時の南平岸旧社屋の代表点)。

`series`列には企画名(例: `サイコロ4〜日本列島完全制覇〜`)が入る。放送回数の情報が
取れないため、シリーズ=放送回の代わりにシリーズ=企画としており、`settings.json`の`series`が
企画ごとに2文字以内の略称ラベル(例: `サ4`。地図ピン・バッジに表示される)と系列ごとの色
(サイコロ・釣りバカ・試験に出る等は同色)を定義している。並び順はjawiki記事の企画の掲載順
(=CSVの出現順)。

`categories`列は当初`series`列と同じ企画名だったが、企画数がそのままカテゴリ数になって
絞り込みチップが見づらかったため、**`サイコロ`・`北海道企画`・`その他`の3つに整理し直した**。
`サイコロ`=サイコロ1〜6、`北海道企画`=道内で完結する企画(カントリーサインの旅I・II、
十勝二十番勝負、釣りバカ対決各回、粗大ゴミで家を作ろう、30時間テレビ、カルトクイズ世界大会、
シェフ大泉各回、onちゃんカレンダー)、残りが`その他`。道外へ出る企画(闘痔の旅=北海道→青森
など)は北海道発でも`その他`に入れている。企画そのものは`series`(=ピンの色・ラベル)で
引き続き区別できる。

**具体的なスポットの採否・説明文・各企画との対応関係は未検証(要確認)。** 2つのパートに
分けた別々の調査を1ファイルに統合したため、同一スポットが複数企画に登場するケースが
稀にある(例: 厳美渓は「桜前線捕獲大作戦」「東北2泊3日生き地獄ツアー」の両方に登場)。
[buratamori](../buratamori/README.md)と同様、先に登場した企画の行だけを残し、あとの企画に
登場したことは`description`末尾に追記して統合済み。`key`列はスポット名(名前重複時のみ
`名前_2`の連番サフィックス)で全279件に付与。

内訳の経緯:

- 37件は後から追加したもの。うち22件はルート作り直し(後述)の際に、jawikiの行程節に
  地名があるのに未収録だったスポット(サイコロ1・2の出発地の六本木プリンスホテル、
  サイコロ3後編の津名港・神戸ヘリポート・但馬空港、原付東日本のカブ購入店・竹田輪業ほか)。
  残り15件は、**企画そのものがまるごと未収録だった6本**を追加したもの:
  「日本全国絵ハガキの旅」「日本全国絵ハガキの旅2」「第1回水曜どうでしょうカルトクイズ
  世界大会」「シェフ大泉 車内でクリスマス・パーティー」「釣りバカ対決!わかさぎ釣り2」
  「onちゃんカレンダー」。この6本の追加に伴い`settings.json`の`series`/`categories`も
  31→37企画に増え、釣りバカシリーズのラベルは放送順(門別=釣1/氷上わかさぎ=釣2/
  わかさぎ2=釣3/屋久島=釣4)に振り直した
- さらにレギュラー終了後の国内企画5本を追加し、現在の39企画になった
- スポット行を持たない企画が3本ある(シェフ大泉 車内でクリスマス・パーティー=HTB駐車場、
  onちゃんカレンダー=HTB第1スタジオ+ハワイ・ラスベガス、釣りバカ対決!わかさぎ釣り2=新篠津村。
  いずれも会場が他企画のスポットと同じ地点のため、そちらの`description`末尾に追記する形にした)
- 削除・付け替えたもの(いずれも旧keyは`excluded_candidates/exclude.txt`に理由付きで記載):
  `利島`は「ゴールデンスペシャル サイコロ6」で**サイコロの選択肢に挙がっただけで実際には
  訪れていない**ため削除、`バスタ新宿`は企画当時(1997年)に存在しない施設名だったため当時の
  `新宿高速バスターミナル`として付け直し、`苫小牧港_2`は`苫小牧港`と同じ地点のため統合
- `新千歳空港`は「サイコロ3」後編で先に登場しているのに`series`が「サイコロ4」のままに
  なっていたため、「スポットを追加するとき」のルール(先に登場した企画に属させる)どおり
  `サイコロ3〜自律神経完全破壊〜`へ付け替え、`description`もサイコロ3を主語に書き直した
  (サイコロ4・5のことは末尾への追記に回した)
- `大町温泉郷`(長野県大町市)は、サイコロ4で信濃大町駅からレンタカーで伊勢神宮へ向かう
  途中の立ち寄り先。jawikiの行程節には出てこないため未収録だったものを追加した
  (座標は大町温泉郷バス停=Nominatimで代用)
- `東京2泊3日70km`のラベルは、数字だけで何の企画か分からない`70`から`東京`に変更した

## routes.csv

jawiki記事の企画ごとの「行程」節・「旅程」節・日別の見出し(原付シリーズ・対決列島など)に
**書かれている順番**をそのまま`seq`にしたもの。かつてはspots.csvの行順を機械的に`seq`に
していたが、行順が移動順になっていない企画が多く、**旅の出発地(東京)がまるごと抜けている**
という問題があったため、記事の行程に沿って全ルートを作り直した。作り直しで直った主なもの:

- サイコロ1・2の出発地(六本木プリンスホテル→新宿高速バスターミナル/東京駅)、
  サイコロ5・6の羽田空港以降の深夜バス区間、東京2泊3日70kmの出発地(羽田空港)、
  原付東日本の出発地(銀座)、桜前線捕獲大作戦の出発地(仙台・西公園)を追加
- 移動の途中にある地点が末尾に置かれていたものを本来の位置へ移動
  (サイコロ2の壇之浦PA=はりまや号の休憩地、サイコロ4の千歳IC・新千歳空港=冒頭のドッキリ、
  闘痔の旅の函館港・青森港、十勝二十番勝負の日勝峠、カントリーサインの旅の寄り道4地点、
  原付東日本のだるま屋ウィリー事件現場、対決列島の天文館むじゃき など)
- 四国八十八ヵ所は札所番号順(I・IIは順打ち、IIIは逆打ち)に整列
- 1回のロケで同じ地点を2度通る企画も、**1ルート内で同じ`spot_key`を何度でも使える**ため
  分割しない(サイコロ6は`第1夜`/`第2夜`の2ルートに分けていたが、その分け方だと
  松山空港→羽田空港の移動が抜けるため、羽田空港・新大阪駅・高知空港をそれぞれ2回経由する
  1本の`ゴールデンスペシャルサイコロ6`に統合した)。サイコロ3を`前編`/`後編`のまま
  残しているのは、放送自体が前後編に分かれ、後編が別ロケ(札幌から再出発)として始まるため
  (**ルート名34本のうち2本はこの前後編**なので、ルートを持つ企画は33本)
- 各ルートの`leg_description`列に移動手段(深夜バス・特急・フェリー・原付カブ・車・徒歩など)を
  記入した。またクイズ!試験に出るどうでしょうは企画がHTBスタジオ発のため、先頭に既存スポット
  `北海道テレビ放送`(南平岸旧社屋)を経由地として追加した。原付東日本のカブ購入店は`銀座`から
  実際の店名`竹田輪業`(中央区)へ、湯沢温泉は関川村付近から`越後湯沢温泉`の座標へ修正した。
  原付東日本は出発地`銀座`を銀座四丁目交差点に置き直し、カブを購入した築地のバイク店
  `竹田輪業`を2番目の経由地として新規追加した(湯沢温泉→越後湯沢の`key`は`湯沢温泉`のままで
  ルート参照を維持)
- 「3夜連続深夜バスだけの旅」「対決列島」の出発地を、出発式典の行われた北海道テレビ放送(HTB)に
  変更し、対決列島の函館→青森を青函フェリーから特急はつかりに修正した

**行程節に地名が書かれていない立ち寄り先(宿・対決場所など)までは網羅していない。**
未収録と分かっているもの: 闘痔の旅の1軒目「薬師温泉(ニセコ町)」、東京2泊3日70kmの
多摩川緑地、5周年記念…の出発地「大通バスセンター」。また経由地が1件以下の企画
(門別沖釣りバカ対決・氷上わかさぎ釣り対決・わかさぎ釣り2・シェフ大泉 夏野菜スペシャル・
シェフ大泉 車内でクリスマス・パーティー・第1回水曜どうでしょうカルトクイズ世界大会・
onちゃんカレンダー・30時間テレビの裏側全部見せます!)は矢印が引けないためルートを持たない。

## ライセンス

座標のみosm_japan(OSMのローカルミラー)およびNominatimで1件ずつ裏取りしているが、
説明文・立ち寄り順は一般知識からの作成。Overpass APIでの一括抽出ではなく既知の地点を
個別に参照した程度のため、ODbLの表示義務は適用されないと考えている(境界事例ではあるので、
大量に追加抽出する場合は改めて要検討)。
